# 养号播放按持久设置自动运行（2026-10-18）

## 用户目标与当前缺口

用户明确要求：系统运行时，养号应按设置自动启动。现有 playback 维护可核验原身份、研究同领域内容并实际播放，但参数只在手动页面会话中，未进入后台持久计划；4小时同步和24小时分析不包含播放。

先文档、子 agent 按后台/前端/维护集成实施，主 agent 审查、组合验证并部署。不改变已冻结创作、媒体、发布及模型预算。没有自动点赞、评论、发消息或付费创作授权；自动路线明确强制这两项互动关闭，手动单次互动确认不变成长期授权。

## 本次默认与配置范围

仅当前已绑定 account01 启用一份自动播放计划，沿用手动页面现有播放默认值：20条、每条最多90秒、每轮最多20分钟、最低相关度60；计划间隔24小时。频率明确作为本轮实现默认值告知用户，可在前端修改。其他未配置账号不自动启用。点赞/评论始终关闭；不替用户开启手动页互动选项。

设置按账号 UUID/key 持久保存，包括 enabled、interval_seconds、options、授权来源、updated_at。保存启用的新计划后按到期执行；重启不重置次数、不补跑离线期间所有批次、不重启未决原任务。原同步和分析的设置与到期时间保持。

## 后台接线

- 在既有 account_refresh.db 增量增加 playback_policies/playback_accounts/playback_runs。所有账号计划共享控制、互斥和未知运行门；恢复不得越过未决 playback。
- 约定 API：`set_playback_policy(account_uuid, account_key, enabled, interval_seconds=86400, options=None, *, authorization_reference='', path=DB)`；snapshot 增加 playback_policies / playback_accounts / playback_runs。options 为只含既有 PlaybackOptions 配置的字典，拒绝 auto_like/auto_comment 为真。
- startup catchup 和每分钟扫描使用同一调度；初次启用到期即执行，重启只补一次。现有脚本继续唯一启动入口，不增加另一个重复 daemon。
- 长时间播放不阻塞调度扫描及其他账号。持久 claim 在锁内核对账号暂停、启用配置、原运行及身份；有界后台线程执行（最多两个实际播放 worker，满时保留待到期，不先占无限队列）。同一账号其他任务等待此运行完成。
- 进入实际调用前再核对当前控制/策略，暂停或停用不触发新任务；已在途正常保存终态，不能被当成尚未派发重发。后台中断保留原 ID，结果未知停止，不盲重试。
- 只调用既有 AccountMaintenanceService.run(mode='playback')，使用真实绑定会话、参考关键词与实际播放验证。异常保存具体结构错误码并暂停账号，前端待办可人工关闭；关闭不自动恢复。
- 合理无候选与实际访问异常区分：空候选保存 skipped/无播放证据，不伪写成功观看；具体结构码由维护集成 agent 核对，不通过固定样本数或填字段假验收。
- 运行 lease 根据整轮配置上限增加必要余量，避免合法长轮次被固定短锁当成失联；原未知锁、日配额、人工窗口互斥保持。
- 主审发现原 playback 每日3次错误复用账号全局次数，会被同步/分析耗尽；按账号/UTC日增加播放专属持久配额，仍最多3次，首次承接既有维护日志中的当日播放尝试，全局历史计数保留。底层任何其他非空 owner（含过期或无时间的未知锁）均不得被自动业务抢占。

## 前端接线

- “抖音账号 → 自动更新与日志”增加按所选账号保存的自动播放计划；启用、间隔、条数、单条上限、整轮上限、相关度可见可改，默认值如上。
- 管理员可修改；汇总视图只查看各账号，不把同一设置无差别写所有账号。显示不含点赞/评论的实际持久配置、下次时间、等待/执行中/暂停/未知、最近结果与播放验证数量。
- 继续15秒本地状态刷新；渲染不访问平台，不因刷新重复保存或提交，不要求用户每一轮重新点确认。
- 原手动入口继续存在，自动设置与单次手动互动严格区分，不迁移浏览器 session_state 中没有有效持久授权的互动开关。

## 责任边界与验证

后台 agent：第三计划状态机、异步派发、共享 admission、真实维护调用与模块测试。前端 agent：持久设置、状态展示及 AppTest。维护 agent：现有服务的结构跳过/异常码、session/lease适配与业务回归，和后台协商返回合同。主 agent：审查实际生产调用链、配置默认/范围、未知记录、关闭待办兼容，组合回归、备份及安全空闲重启；启用当前账号一份计划并核对实际原 ID/回执。

覆盖：配置持久/禁互动、重启不重领、同账号三计划互斥、跨账号不被长播放阻塞、暂停/停用前后、原未知任务、lease、真实请求参数、空候选不写观看、前端账号隔离/权限/无重复渲染派发。真实账号执行若触发验证或失败保留前端待办，不把模拟通过当实际播放成功，不自动重派。
