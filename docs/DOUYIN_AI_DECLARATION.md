# 抖音发布的作者 AI 声明

用户于2026-09-20反馈两条已发布视频由平台识别后添加AI标签，要求改为发布者主动声明。项目AI视频默认在发布前选择平台的“内容由AI生成”选项；文案、话题中的AI字样和平台自动标记均不能替代此步骤。

## 当前实现

- `PublishRequest.ai_generated` 默认 `True`；自动制作发布和监控批量上传明确传入 `True`。仅非AI素材可由调用方明确传入布尔 `False`，字符串不会被当作跳过开关。
- 上传、填表和设置可见性后设置声明；等待交互后重新读回，点击发布前再次检查。未确认时返回 `ai_declaration_unverified`，不继续发布。
- 声明检查经现有浏览器子进程执行，支持带可访问标签的复选框、单选框、开关、原生下拉框及有可读已选值的combobox。可通过“自主声明”等入口或旧“高级设置”入口展开。
- 选项已选中则不反向切换；弹窗内选中不视为已提交，需声明弹窗确认、关闭后重新读取表单。仅页面出现AI文本不算通过；不认识的自定义控件或多个匹配项直接停止，不猜测成功。
- `data/publish_runs` 的每次日志记录是否要求声明、设置/核验步骤、结果与本地截图。发布监控页显示相应状态。旧发布回执不回填主动声明记录。

## 验证范围

本次完成本地选择/读回、已选幂等、未选、未提交弹窗、平台标签误判、点击无效、多匹配、发布前阻断及重复提交保护测试。当前工具没有可接管的抖音登录页，未声称线上页面已实测，也未为测试发布新作品。下次授权上传时必须以该账号实际页面的已生效状态为准；未兼容的页面停止并保留失败记录。

抖音[用户服务协议第4.4条](https://www.douyin.com/draft/douyin_agreement/douyin_agreement_user.html?id=6773906068725565448)要求对相关AI非真实音视频作显著标识，并说明平台也可添加提示。主动声明不会承诺去掉平台AI标签。本次修订不改变已发布作品。
# 2026-09-20 补充：浏览器自动化声明与发布后核验

- 不接发布接口。虚构剧情的 `PublishRequest.fictional_story` 默认为 true；纪实作品须显式设 false。简介首部自动加入“剧情虚构，非真实事件。”，重复运行不重复追加，提交前再次读回。AI 声明仍使用平台控件；不盲选第二个可能互斥的自主声明选项。
- 发布后只对准确的抖音作品链接检查。作品管理页仅标题命中、审核同步延迟、无法唯一定位作品正文、声明缺失、播放器未就绪或出现审核提示，都记为 `post_publish_verification_pending`，不记最终完成。
- 详情页检查当前支持唯一含视频的语义 article；未知页面结构保守待核验。保留链接、检查 JSON 回执和可获取的详情截图。AI 标签来源无法从展示判断，作者主动声明以提交前控件回执为证。
- 待核验属于已接受提交，保留防重复提交锁；批次暂停后续作品。后续应针对该作品只读核验，不能重新上传。播放器就绪不等于完整听看审核。
- 本次仅离线测试，没有实际发布作品或修改现有作品；真实账号页面结构尚未验证。
