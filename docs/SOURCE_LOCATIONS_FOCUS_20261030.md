# 地点节点专项修改与真实测试（2026-10-30）

用户“好”同意逐点处理地点问题。范围为完整第19章前情、第20—21章目标，沿用语义覆盖修复，不修改人物归属节点。

## 原因与改动

旧提示已禁止补地理关系，但程序只要求有地点字段，不能识别把前面的“商场”和后面的“便利店”拼成“商场便利店”。本次增加地点原段号和原文连续地点词，程序核对来源及原词，并将逐场原句证据交给独立审核。

原词命中只证明出处，不证明本场人物正处于该地。否定、回忆、计划和出入转移仍需语义判断。检查始终返回 semantic_acceptance=false；未做无人放行或生产默认迁移。

实现：src/content_factory/novel_adaptation/restricted_transcription.py 的 location_prompt、location_diagnostics、location_review_prompt；scripts/run_restricted_transcription.py 新增 source_locations 专项目标，保持同一完整原文及候选绑定。

## 验证

20项离线回归通过，证据 data/qa/source_locations_20261030.xml。覆盖无据地点组合、错误出处、待核、否定原句不能自动语义通过，以及真实两阶段入口的模拟接线。程序测试不代表模型内容通过。

MiniMax-M3.1-Flash 两次真实调用311/312，分别20154和21986 reported tokens，共42140。累计312次、5872687已知tokens，pending=null；本次310→312工程窗口结束，不重跑。完整输入与上一轮逐值相同。

## 真实结果：未通过

1. 最后场只写“便利店”，未再加“商场”或“乐园附近”。此具体错误本样本未复现，不证明稳定修好。
2. 地点输出全用“名称（段号）”，没有遵守“段号|原文地点词”；11个地点字段被程序拒收，未容错改成成功。
3. 第20章P074已经“转身出了店门”，下一场第21章P001—P011仍被放在“童装店”。原词存在，但当前地点继承错误。
4. “正想上楼”与实际下楼混入同一地点列表；公交车和卫生间本身有据，却分别挂在没有该词的P036/P025上，正确原词见P035/P029。不能把引用错位一律判成新增地点。
5. 原生完整输出的38条对白只有引用标签，没有台词正文；另有一场时间字段粘连。核实 native stop 正文、解码正文和保存正文相同，非保存丢字或截断。单次样本不能证明新增地点格式造成对白退化。

## 审核可靠性

模型审查抓到了离店后的地点继承、首场引用无据和导购跨章引用。但把38处对白缺正文误说成各类音画格式问题；接受计划上楼作为地点依据；个别建议仍猜对白人物、误改系统提示与对视顺序。主助手没有照单采纳。

普通微动作仍允许；便利店画面写“路过”，不能仅因地点栏写便利店便宣称已画进入店内。省略号不要求保留字形或独立镜头。避免把风格或普通表演补足混成剧情错误。

## 下一步边界

地点词出处和地点状态连续性需要分开处理。优先把本场“处于、离开、路过、拟前往”与已有原文转场句对应，而非再堆完整自由审核或建立全书日常位置库存。此部分尚未实现。对白缺正文作为另一项协议退化留证，未在本轮混改。
