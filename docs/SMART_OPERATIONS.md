# 智能运营流程

## 自动执行

- 每 4 小时读取一次绑定账号的创作者后台作品指标。
- 每 24 小时按最近已发布作品提取两个主题，采集相关抖音视频并生成运营报告。
- 程序离线期间不补跑历史次数；下次启动只补一次到期任务。
- 流程只读取数据，不发布、不点赞、不评论。

当前 `account01` 会从已发布标题提取“装修合同”和“租房押金”。报告写入 `data/smart_operations/account01/`，调度状态保存在 `data/account_refresh.db`。

## 数据口径

- 自有作品的播放、点赞、评论、分享和收藏来自创作者后台接口。
- 完播率和 2 秒跳出率沿用最近一次实际读到的创作者后台记录，并标明观察时间。
- 关联视频的标题、作者、标签、时长和页面展示数字来自抖音搜索页。
- 页面展示数字没有明确语义时保留原值，不能称为点赞量，也不能用于自动选题或剧本放行。
- 评论页面解析为 0、但后台评论数大于 0 时，记录为评论同步失败，不能写成“没有评论”。

## 安全验证与缓存

抖音搜索页可能要求人工安全验证。可见浏览器手动执行时最多等待 3 分钟，验证后在同一页面继续采集。后台无头任务不会等待人工操作；它会继续同步自有作品数据，并在 72 小时内使用最近一次成功采集的关联视频样本生成报告，同时标明 `research.source=cached`。

后台浏览器命令有响应超时，异常日志只保留脱敏后的第一行，不记录 Cookie、请求头或带查询参数的地址。

## 手动运行

```powershell
.\.venv\Scripts\python.exe scripts\run_smart_operations.py --account account01
```

遇到搜索安全验证时使用可见浏览器：

```powershell
.\.venv\Scripts\python.exe scripts\run_smart_operations.py --account account01 --visible
```

“元数据运营报告可用”和“可以自动生成剧本”是两个状态。只有原视频音画证据和指标口径满足研究门槛后，才允许进入自动选题或剧本生成。
