# 忠实视频剧本 Agent 两轮整链测试

目标是忠实转写小说为可生产视频的剧本；允许自然表演与普通布景，不能新增人物关系、背景经历或事件结果。不是重新创作爽点，也不先强拆15秒。

## 实际范围与流程

同一批完整第20、21章，完整第19章只作前情。两轮都执行：理解 → 场次规划 → 完整剧本 → 连续性审查 → 忠实度审查 → 候选承接。第一轮完成后主助手完整阅读并定位原因，修改Agent输入与提示，再执行第二轮。不是两个不同章的小样，也不是自动诊断返修闭环已实现。

全部调用 MiniMax-M3.1-Flash/medium，12次，189,924 reported tokens。累计302次/5,680,259已知tokens；135、290未知消耗另计，原290 STATE SHA核验未变。没有新增pending。工程304上界剩2次未使用，两轮自然结束，不为用完次数继续调用。

## 第一轮结果

六阶段完成，正文8场。分析将目标第20章开头误标前情，规划继承该错误，正文漏演叶东安慰叶寻及苏墨夜间思考。忠实度审核捕获遗漏，但连续性审核根据出场名单猜排行、建议改原文姐姐称谓；将普通下车转场误判交通矛盾。承接仍扩写早餐全部吃下、旧衣留家等无必要信息。未验收。

第291次完整普通文本stop不符合原工具合同，已保留原失败；续行用流终态和原生SHA核验后原样映射为text，未重发291、未手改内容。后续兼容器拒绝length、未知流或pending。

## 第二轮修改与结果

程序按完整原章原段生成source_index，固定目标/前情归属；场次直接读原文，不接理解摘要；编剧保留完整原文和参考场次，不接理解摘要；审核要求明确矛盾双方证据，区分普通转场、排行推断与剧情错误；承接收窄为后场相关状态。

正文22场，恢复目标开篇，原文覆盖与转场审核有改善，但仍未通过：

- 自行补全兄妹排行，同时把姐姐最好看了分给标成老三的叶北。两份审核仍误认排行有原文支持。
- 买完衣服新增走，回家，后面继续火锅、乐园；两审捕获。
- 约定送货后又让孩子拎袋出店和返家；连续性审捕获，承接仍沿用。
- 总背景写周六、周日；实际前夜到次日周六。审核建议改成仅周六，仍漏前夜。
- 袁军心理疑问变出声台词，多处第三人称心声仍不自然。

回忆里新增妈妈掖被角端饭应退回原文心理表达。普通灯光、表情、衣领小动作、洗手间招呼和不指定车型的转场允许，不作为剧情硬错。

## 技术判断与边界

本次证据支持：来源归属和上游错误传播可以通过输入隔离改善；但仅增加自由文字分析/审核无法保障人物关系与行动状态。编剧仍自行补齐、审核仍把候选背景当事实。下一步应固定仅当前剧本所需的身份关系与行程/道具状态，让具体对白归属受其约束；原文不明确的排行不要求补齐。不再堆全书人物百科或自由审核轮数。

11项程序回归通过（data/qa/faithful_full_v4_workspace_20261030.xml）。一次默认临时目录权限导致7项setup错误，改用项目隔离临时目录后通过，失败报告保留。程序通过不代表语义通过。

两份候选及审核、原生请求响应、账本均保留。没有手改剧本、没有释放承接、没有视频/发布/服务重启/默认迁移。第20章曾用于历史试验，不是严格独立留出；69章整链仍未验收。
