# 全书问题检索：三个连续片段实测（2026-10-29）

结论：三个样本全部生成，全部未验收通过。保留有用检索与程序约束，不扩大无人放行生产。

## 开发和验证
完整69章原文建本地词法检索索引；MiniMax针对目标原文提出问题，程序查全书，提供叙事位置之前的命中及邻段，模型选择后编剧。后文命中仅留证，unknown不作为已知答案。每段直接上文两段自动附带，不使用人工指定前文章范围。

修复了两处真实合同缺陷：共享候选池与逐问题ID限制不一致；当前目标原文可见却不允许选其ID。目标命中去重，旧失败保留。新增已知完整但来源链接失败的输出保留及续测，不重发旧调用，不修改模型文本。30项程序回归通过，不代表内容通过。

## 根因与方向判断
1. 提问仍是复合问题：身份、身世、年龄、地点混在一起，部分有证据就整体supported；检索增加了材料却未解决真正缺口。
2. 前态不能完全依赖模型主动提问。B只见紧邻两段，早餐时间被隔在更前面，生成自行填黄昏。需要每场必带精简时间/地点/在场/动作状态，原文证据绑定；当前未接入。
3. 来源ID和原句匹配只能证明引用存在，不能证明改编语义正确。C把原文“苏墨说道”连到新增整理衣领动作即是例子；表演可添加，但来源与创作应分开。
4. 当前每段从原文接续，未接受的上一段模型稿未传给下一段。这不是已验收跨段状态链。

建议：保留问题检索辅助，改为“小前态必带＋单问题检索＋局部歧义确认”。不继续以增加自由审核轮数作为自动放行主保证，也不据此换框架或声称模型整体不行。该建议尚未开发；现有46集及69章整链未验收，无媒体调用、发布、服务重启或默认迁移。
