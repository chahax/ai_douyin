# 比较记录到正文、全文双审的独立接线

本实施接续全文v5协议与paired纯模块，不改冻结v25/Session3或原635。它只新增纯workflow适配及离线接线，不建生产claim，不新增调用，不重领规划/导演或返修容量。

## 需要实际接上的接口

新增 creative_goal_context_workflow_v26。scope2/source2/commitment继续原合同；drama使用显式新原生版本，在原闭合合同加入paired_checks，旧审查不能代替新比较记录。新原生报告总验收必须同时满足原戏剧/制作范围检查与完整paired决策。

检查旧合同的必要确定性投影只存在内存，须明确不是旧原生报告；原生文档和SHA始终保留，不允许把旧631/635清洗成通过。纯模块已验字段的失败不能通过修改引用、丢掉反证或伪造旧判断绕开。

正文实际请求加入只含引用与原生解释的通过快照，核对goal、比较context、原生比较文档及完整四审bundle身份。一个目标的fail/unknown都阻断正文。R01和完整同源三源仍在实际请求，不能只在manifest写名。

完整语义请求在v5统一协议上加入相同目标对真实steps的复核；物理包仍保留全部原状态检查。适配提供与新driver2匹配的显式part、bundle验收对象，不能依赖冻结driver的模块全局。完整raw模型script、加编译元数据的script及实际request身份分别核对，正文steps不变须逐项验证。

## 返修归属

比较失败仍须有原生显式返修目标：无fail为none；全文有fail为script或plan。不可从中文required_revision猜。若仅新增比较项失败，检查旧协议的投影只能派生该投影自身的目标，最终路由保留新原生显式目标及反证；不能把投影当一份通过的旧审查保存。unknown始终停止。语义、物理、bundle三处均按driver2的valid/accepted隔离。

## 最低离线验收

实际627准备新drama请求，引用目录必须与原无损G/C逐字一致，原631缺paired不能采用。通过完全合成的明确标记样例验证四审到正文快照到全文语义复核及双审交接；实际634只作源绑定和负例回放，不能凭手填合成pass宣称修好真实剧情。漏比较、假quote、换goal/bundle、快照重复、raw/compiled混淆、来源R01遗漏、失效目标归属、格式失败被当正文失败都须拒绝。

实际生产入口及授权另行核对，不因本纯接线或十轮复盘自动恢复旧RUN。完成只意味着新纯适配可离线验证；真实语义能力及完整作品仍需后续受限生产验证。
