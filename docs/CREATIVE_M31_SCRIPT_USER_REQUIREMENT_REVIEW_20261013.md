## 上游流程原因：已有实际请求证据

529实际请求中的冻结brief包含：

- f1：“本故事只展示核对工资与争取书面结算明细的互动过程。”
- f2：“结尾不替观众对争议结果下结论，仅以老韩看工资条的停滞作为可见留白。”

简报已经把创作目标收窄为手续交涉，并指定薄弱结尾。M3.1服从这份简报，也可能仍不符合用户长期要求。因此不能只归咎新模型或视频模型，更不能只压字数、换同义词、追加禁止词。

“不宣称必然违法、赔偿或胜诉”与“片内人物选择产生可见后果”是两项可同时满足的要求。当前上游把未解决法律争议与不提供片内结果捆在一起，后续应在新原生简报/规划合同里纠正；不得手改已经冻结的f1/f2迁就正文。

审核也有实证失效：530漏掉全部21句对白检查，已填的制作、情绪和结尾项多为pass，仍漏掉关本、放纸和站坐前提。其出站Schema允许空数组，本地要求完整覆盖，实际已拒绝，不是有效全文审查通过。见 `docs/CREATIVE_M31_FLASH_SCRIPT_TEST_REVIEW_20261013.md`。
