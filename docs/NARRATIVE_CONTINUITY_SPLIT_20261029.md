# 剧情表演与连续性分层试验

## 已确认的原因

旧六场候选长450.5秒。人物进出等必要连续性与做饭器具的细粒度操作使用同一输出合同，导致返修依赖过多，并把程序状态说明直接变成冗长表演。状态重放通过并不能证明节奏、自然程度或原文理解正确。

## 新入口的实际范围

`scripts/revise_narrative_adaptation.py` 是独立候选生成试验，不是生产默认。

输入完整原文第1—3章作为上下文，第二章作为本集情节边界；沿用已登记人物身份、六场顺序与地点。模型输出世界与人物关系、视觉方向、逐场动作/表情/镜头/对白/时长，以及显式影视补足和必要连续性义务。源材料保持原样，不发送旧完整稿要求机械缩写。

本轮240秒是实验剪辑上限，不是小说所有剧集的固定时长，也不是质量通过标准。模型须自行分配时间，可以短于上限；背景可浓缩、做饭可明确省略时间，不能删除分肉、误解、拒绝辍学等核心因果。

## 分层边界

1. 原文事实与人物身份保持独立；程序只验证引用存在及目标章边界，不能据此声称语义正确。
2. 表演层自然描述动作，不要求每只锅碗逐项建账。视觉新增单列，不能冒充小说明示事实。
3. 人物入离场、关键物品持有、知情变化等先列出连续性义务。后续仍需接入独立状态核验；当前文本义务不是已执行的状态证明。
4. 必须审查真实新候选，再决定局部返修。不能拿新结构绕过旧问题，也不能把人工改稿作为模型成功。
