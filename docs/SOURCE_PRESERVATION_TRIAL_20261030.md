# 原文明确信息不改、未知不猜：一轮修复与输出

用户要求确认方向后修复并跑一轮。该方向作为忠实转写原则成立，但不能把模型上轮判断等同已确认事实，也不意味着禁止普通光线、微动作和美术设计。

## 本轮改动

画面与审核共同使用 FACT_PRESERVATION：保留原文明确信息的主体、行为、对象、条件和时间层；不把过去见闻/心理/设想重写成当前可见事件；未知保持开放，场景标题与地点栏同样不能猜归属。普通表现补足允许，不要求每段都有画面。

明确当前是剧本整理，音画分组可接受；不把缺少逐镜头同步当本阶段异常。

程序支持同章连续原段范围，包括紧凑范围和完整起止ID，验证全范围为真实目标段、拒绝倒序/跨章/虚构段。审核可追溯范围原句，但来源有效不自动语义放行。上一稿49格式错误可离线通过新解析，旧语义错误仍完整保留，不伪造旧任务通过。

固定原文与67条已知完整声音，不重新生成声音，只测画面与审核。声音表仍标语义未验收。

## 结果：整稿未通过

本次六个孩子数量保持，未再出现下车后贴车窗、商场橱窗里出现同学见闻、末场手捧新衣等错误。这仅是本样本观察，不是泛化通过。

仍有明确问题：

1. 便利店变为“商场外便利店附近”，原文没有地理归属，仍在猜。
2. 固定声音表漏选“去融创乐园”的计划内容与告知事件，只留为什么这样奖励的解释；画面只画孩子兴奋，缺少反应触发信息。错误来自上游声音内容选择，锁定后下游不能擅补。
3. 苏墨离开去卫生间后，21-4人物栏仍有苏墨；下一场才回来。
4. A063来自P079，却放在原段范围P074—P078的场次。属于范围元数据缺漏，不是音画分组错误。
5. 三个未知说话人仍保留，没有偷偷署名，但不是已完成具体配音角色分配。

普通上下铺、门帘、反光等设计不一律等同硬剧情错误，需与后续固定资产协调。模型审核仍会把哥哥/姐姐称谓当原著冲突、把服务员没有动作等同不在场，主助手未照单采纳。

## 结论

“已确认不改、未知不猜”是正确边界；本轮没有证明仅追加这段提示就能可靠生产。剩余原因分为画面擅补、必要告知漏选、在场与来源元数据未承接。下一步应对这些责任点定向处理，不再扩充大段自由摘要或把每个制作细节都变成事实硬门。
