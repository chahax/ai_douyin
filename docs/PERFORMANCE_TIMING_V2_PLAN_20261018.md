# 对白状态、发音量与额外反应：v2修订范围

用户指出v1中听懂确认、防备松开/愧疚/释然、重要选择/压住泪意的参考区间仍偏长，并要求确认对话不同状态的字数与时间。v1将可见情绪变化与台词后的额外停留合在一列，且把情绪对白大体放慢，粒度不足。本轮分别核对，不再按情绪名称统一加时间。

1. 独立`performance_timing_reference/v2`明确：情绪状态可以贯穿对白，短暂可见变化尽量在刺激到达后的对白中表现，台词后默认不加停留。听懂确认可先按可见变化0.3—0.7秒、额外0—0.3秒估；防备松开/愧疚/释然按0.4—1秒、额外0—0.4秒；重要选择/压住泪意需变化时按0.6—1.2秒、额外0—0.6秒。直接给已经成立的状态不加时间，超出参考需具体表达作用，不作为程序硬拒门。
2. 对白按实际说法与发音量分别估算：平静说明3.5—4.5单位/秒；利落追问/回答4—5；认真强调或克制承认3—4；带笑/眼中有泪但仍连贯3—4；明确哽咽断句2.5—3.5。生气、低声、愧疚本身不自动决定快慢。提供每单位秒数倒数、句子发音量/预计声音时长、真正停连及交接核对。数值仅项目创作初值，不是录音实测、行业标准或内容分类器。
3. 子agent实现独立规范与纯文本估算辅助，原v1、content_end、v9/v10冻结模块不改。新准备入口与网页由主agent切到新版本；同一个brief规则仍进入五个文本阶段，旧任务走原恢复，不补写或放宽硬范围。
4. 子agent以当前完整v3为源，逐条核对18条对白的说话状态、实际发音文字、发音数量、句内停连、分配窗口与估算，另存v4完整候选及对白排时表。重点处理S03/S04/S05末尾1.1／2／1.8秒反应，把状态变化安排在对方话内或下一句回应中，避免末句结束后再重复演一遍。不要为了缩短而催词、改主线、删对白或取消真实的因果反应。
5. 主agent审查所有句子、短句交接和段首段尾，保存SDK本地预览及旧版保持证据。没有新MiniMax/DeepSeek/媒体调用，不重启旧十轮、不改原视频或假称生成质量通过。
