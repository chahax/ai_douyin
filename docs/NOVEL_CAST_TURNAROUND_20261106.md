# 当前完整剧本：全员人物多方向候选

用户要求所有人物沿用多方向/细节标准，并询问模型。本轮使用本地 **FLUX.2 Klein 4B distilled**：BF16主模型、Qwen3-4B FP4文本编码器、4步、768×1024。没有云调用、额外下载、依赖升级或服务重启。

当前已生成的前三章完整剧本共9名入镜角色：苏墨、叶东、叶南、叶北、叶寻、叶嫣儿、叶西决、高个男人、矮个男人。每人9张，合计81张本轮原生生成图。不是整本69章所有提及人物。

目录 `data/image_model_trials/20261106_novel_cast_turnaround`：

- `CATALOG.md`：九人正面总览、九套多视图和各自单图目录链接。
- `selected/<人物ID>`：每人正面、左右前侧、左右侧面、背面、脸/衣/手细节9个PNG。
- `characters/<人物ID>/contact_final.jpg`：单人九宫格；`cast_fronts_final.jpg`为九人正面；`cast_all_views_overview_final.jpg`为81图总览。

之前通用成人/孩子样例不冒充已完成的小说角色。本轮建立具名角色与剧本事实绑定后，重新生成了全部81张。

## 原文事实与造型设计

CAST_PLAN绑定当前剧本SHA与人物/服装引用位置，明确分开事实年龄、设计外观年龄。叶东11岁依据已保存的第五章原文核查记录，叶西决6岁依据当前正文；其他不明确年龄仅作外观设计，不伪装为已证小说事实。旧“叶南十五六岁”不用于造型。

叶北与叶寻按原文共享双胞胎视觉身份：8个独特视觉身份、9个角色ID。叶寻通过已核叶北正面单参照、独立采样微姿态产生，保持同脸同款衣，不捏造疤、徽章、异色衣服来区分。

正面提示词只编译当前单人可见外观；兄弟关系和双胞胎元信息保存在角色卡，不把“六个兄弟”等关系文字送进单人构图，以免诱发多人同框。年龄区间和后续场景相对身高另行控制，不能从独立摄影画面的人物像素高度直接推断实际身高。

## 生成与复核

先8个独特正面共享模型批，再单独完成第二名双胞胎；主代理实际审图并核各人ROI后，三组各21视图，最后各用已审朝右斜侧单图一跳生成9张右侧面。合计6次POST、81张，原生各批约95—149秒。每张有独立提示/噪声/采样/保存节点，共用模型权重不会共用人物上下文。

细节只使用同源局部ROI，避免全身需求与特写冲突、全身+头部双参照拼贴。右侧面按前轮已验证的方法采用朝右邻近角度，不重新重复正面直出朝向反转错误。主代理实际查看全部角色组图和九张右侧面，并独立核81张选定副本与原生文件SHA、768×1024尺寸、各执行history保存节点。

双胞胎胸袋曾被缩略图初看疑为新增；放大原图核对后确认两张基准本就有胸袋，保留正确设计，没有为错误审核意见修改它。证据 `TWINS_SOURCE_CLOTHING_AUDIT.png`。
