# 抖音热点情报：网页采集路线与 Go/No-Go

更新时间：2026-08-26

## 1. 决策结论

从技术角度，当前项目可以用 Python + Playwright 打开抖音公开页面，按关键词浏览视频卡片并提取页面可见的标题、作者、发布时间、互动数和链接，再进行法律领域过滤、聚类和脚本生成。

但从当前平台规则看，**未经书面授权的抖音网页爬虫不能作为正式数据源**。

[最新版“抖音”用户服务协议](https://www.douyin.com/agreements/?id=6773906068725565448)明确限制：

- 使用自动化程序、软件或类似工具接入抖音并收集或处理信息；
- 未经书面许可进行爬虫抓取、模拟下载等行为；
- 使用未经授权获取的内容统计热词、分类、搜索量、点击率、阅读量；
- 未经许可进行内容商业使用或向第三方提供。

[抖音 robots.txt](https://www.douyin.com/robots.txt)还对部分机器人和搜索、视频等路径设置了抓取限制。`robots.txt` 只是机器访问规则，不构成数据使用授权；即使某个路径没有写入 `Disallow`，也不能替代用户协议和书面许可。

所以路线分为三档：

| 路线 | 当前状态 | 建议 |
|---|---|---|
| 未授权直接抓抖音搜索/热门页 | 技术可做，协议风险高 | **No-Go** |
| 人工浏览、人工选择 URL/文本后导入分析 | 可立即实施，仍需控制内容使用范围 | **MVP 默认路线** |
| 获得抖音/数据权利方书面授权后自动采集 | 条件式可行 | **授权后启用** |
| 官方 OpenAPI/MCP 或许可数据服务 | 取决于审批/合同 | **生产优先路线** |

## 2. 为什么“能打开网页”不等于“能爬”

公开访问只说明页面可被普通用户浏览，不自动授予以下权利：

- 自动、批量、定时采集；
- 使用账号登录态运行机器人；
- 复用网页内部非公开接口；
- 长期保存视频、字幕、评论或用户信息；
- 对内容做平台级热词/阅读量统计；
- 把内容交给生成模型改写或用于商业输出。

本项目目标包含“热门分析”和“根据内容生成剧本”，与协议中明确提到的热词/分类统计及内容再利用高度相关，因此不能只用低频、换 IP 或隐藏自动化痕迹来解决。频率更低只能降低技术负载，不能消除授权问题。

## 3. 可立即执行的安全路线

### 3.1 人工选样 + 工具分析

第一版不自动枚举抖音页面，由用户正常浏览并人工选择研究样本，然后导入：

```text
URL
标题/文案摘要
页面展示的发布时间
页面展示的点赞/评论/分享数
采集时间
备注和许可来源
```

导入方式：

- CSV/Excel；
- UI 单条粘贴；
- 用户自有账号后台的合规导出；
- 获得许可的第三方数据文件。

系统只负责去重、法律相关性、趋势评分、话题聚类、TrendBrief 和原创脚本，不自动访问抖音。

### 3.2 许可搜索/数据服务

生产版本优先使用：

- 抖音官方 OpenAPI/MCP 实际获批能力；
- 与数据权利方签约的数据服务；
- 自有账号可导出的创作/经营数据；
- 允许自动采集和分析的其他网站或开放数据集。

每个来源都要保存数据许可、用途、字段、频率、保存期和是否允许生成式处理。

## 4. 授权后网页采集路线

只有拿到明确书面授权，且授权覆盖“自动采集 + 热点分析 + 生成式处理”后，才启用 `authorized_web` Provider。

### 4.1 可采集入口

入口配置化，不把 URL 和 DOM 选择器写死在业务逻辑：

```text
关键词搜索页：法律 / 普法 / 劳动仲裁 / 离婚 / 合同纠纷等
热门/话题页：只在授权明确覆盖时启用
单条视频页：对已选中的样本补充页面可见指标
自有账号页：仅处理有权管理的账号数据
```

公开的[热门话题 HTML 地图](https://www.douyin.com/htmlmap/hotchallenge_0_1)可以用于发现页面结构，但它不是实时法律热榜，也不代表获得自动采集和数据使用许可。

### 4.2 只采集最小字段

```text
query / page_type / page_rank
canonical_url / public_content_id
title / caption_excerpt / hashtags
author_display_name / author_id_hash
published_at
displayed_like_count / comment_count / share_count
collected_at / parser_version / evidence_hash
```

默认不采集：

- 评论正文和评论用户资料；
- 私信、粉丝、关注关系；
- Cookie、localStorage、设备指纹；
- 原视频、完整音轨或批量截图；
- 页面未展示的内部字段；
- 与热点判断无关的个人信息。

### 4.3 采集约束

- 默认可见浏览器、单 Worker、人工触发；
- 访问频率和每日上限以书面授权为准；
- 没有授权参数时采用保守默认：每页间隔不低于 30 秒、每次最多 20 页、禁止并发；
- 遇到登录、验证码、风控、403、429 或异常跳转立即停止；
- 不使用代理池、验证码识别、指纹伪装或反检测插件；
- 不拦截、重放或逆向网页内部非公开 API；
- 不在采集任务中下载视频或生成脚本；
- 原始 HTML/截图按授权保存，默认不长期保留。

## 5. 法律关键词路线

建议查询矩阵：

```text
通用：法律 / 律师 / 普法 / 法律咨询
劳动：劳动仲裁 / 劳动合同 / 工伤 / 社保
婚姻：离婚 / 抚养权 / 彩礼 / 婚前财产
财产：继承 / 遗嘱 / 欠款 / 合同纠纷
消费：消费者权益 / 网购维权 / 预付卡
安全：交通事故 / 电信诈骗 / 网络侵权
企业：公司法 / 股权 / 合同风险 / 用工风险
```

网页搜索结果受账号、地域、时间、个性化和页面排序影响，输出必须标记：

```text
source=authorized_web
query=劳动仲裁
collected_at=...
session_scope=...
ranking_scope=page_visible_order
coverage=sample_only
```

只能称为“指定查询和采集窗口内的网页样本热点”，不能称为抖音官方全量法律热榜。

## 6. 热门判断

网页一次快照只能提供基线：

```text
sample_score =
    0.30 * visible_engagement_percentile
  + 0.25 * page_rank_score
  + 0.20 * freshness_score
  + 0.15 * legal_relevance
  + 0.10 * multi_author_recurrence
```

只有在授权允许重复访问，且同一内容有至少两个可比快照时，才计算增长速度：

```text
trend_score = sample_score + normalized_metric_velocity
```

网页缺字段或数字是缩写值时应记录 `metric_quality=approximate`，不得虚构精确播放量。

## 7. 项目现状判断

### 本地 apachong 框架评估

`D:\IT\apachong` 的任务恢复、原子证据包、限速和浏览器实例隔离设计可以作为工程参考，但其现有采集器主要面向已登录、已授权的电商管理页面，不是公开抖音关键词热榜采集器，也不会改变本文件的授权结论。

采用边界如下：

- 抽取平台无关的 Source Policy、CollectionJob、Checkpoint、访问预算思想；
- 继续使用 `ai_douyin` 已有 BrowserSession、Scheduler、数据库和生成链路；
- 抖音可见 DOM 解析器和法律趋势模型重新实现；
- 不采用 anti-detect、代理切换、验证码识别或内部接口监听/重放。

因此，“采用 apachong 大概框架”解决的是工程可靠性，不等于获得数据许可。没有书面授权时，网页 Provider 仍必须由 Source Policy Gate 阻断。

当前项目已具备：

- `playwright` 依赖；
- `BrowserSession` 持久化浏览器会话和子进程隔离；
- SQLite/SQLAlchemy/Alembic；
- Scheduler 和单 Worker 队列；
- LLMClient、embedding、Streamlit 和工作流契约；视频生成管线当前停用。

可复用 `BrowserSession` 的浏览器生命周期和基础 DOM 操作，但不能直接复用以下做法作为第三方内容采集方案：

- 捕获网页内部接口并重放；
- 使用发布账号 Cookie 批量抓第三方内容；
- 猜测或调用未公开 API；
- 自动规避平台登录和风控。

建议新增独立 `trend_web_collection` 模块，避免与发布、评论和创作者后台会话耦合。

## 8. Go/No-Go 门

### 未取得书面授权

```text
WEB_CRAWLER_ENABLED=false
允许：Mock / CSV / 单条人工导入 / 自有合规导出
禁止：自动打开搜索结果并批量提取、定时刷新指标、遍历热门页
```

### 取得书面授权

必须登记：

```text
授权主体
允许域名和路径
允许字段
允许用途（热点分析/生成式处理）
允许账号和登录方式
请求频率与日上限
数据保存期限
是否允许保留页面证据
授权开始/到期时间
联系人和授权文件哈希
```

以上信息通过审核后，才把 `WEB_CRAWLER_ENABLED` 打开。

## 9. 最终建议

产品路线仍然可行，但默认不应称为“抖音网页爬虫版”。更准确的第一版名称是：

> 法律热点人工选样与原创脚本助手

获得书面授权或许可数据源后，再升级为：

> 法律热点自动采集、趋势分析与原创脚本系统
