# 每天多轮随机养号与立即一轮

用户明确“自动养号可以每天多次随机现在开一波”。当前account01按既有每日3次上限采用北京时间09-12、14-17、19-22三时段，各一次；每轮既有20条/90秒/20分钟/相关度60，自动点赞评论关闭。当前立即轮计今天次数，未授权扩每日上限、媒体模型、发布或互动。

先通过原set_playback_policy把原24h改8h使当前原计划立即到期，实际由既有后台claim/原身份核验执行一次，不用CLI启动第二浏览器。此为随机功能接入前的明确中间配置，最终随机设置须离线验证并在本轮安全终态后部署。

新随机配置作为playback_policies附属表独立保存，不改旧run/snapshot。冻结seed按账号/北京时间日期/时段用SHA256生成当日各时段秒数，种子持久保存，重启或扫描不重抽。每次锁内根据本地当天全部playback_runs计数/已执行时段跳过已用机会，每日最多3次；错过完整时段不补跑离线积压。旧调用预算、原已用次数、未决claim、同账号互斥和暂停/人工验证门不变。固定间隔旧API/页面默认保持，随机开关/时段在当前账号设置和状态区可查看。

正常claim冻结相同随机配置，finish按下一合法随机时段计算next_due。未知不重派，known失败继续暂停，不靠重置日计数获得新轮数。测试覆盖重启稳定、每日跨日/错过时段、即刻首轮计数、不跨账号、不覆盖在途、禁互动、固定模式兼容及真实后台接线；只在原轮结束且空闲时重启部署。
