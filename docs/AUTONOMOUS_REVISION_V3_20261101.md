# 无人文本闭环：严重度与处理动作分离

用户要求：流程目标是非人工参与，不应以“制作待确认”完成。本次新增独立v3入口，历史v2及原生失败记录保留；没有修改网页默认生产、视频或账号发布服务。

## 原因与修改

旧入口只把核验后的blocking送入补丁。production即使确认成立也留在待办里，模型降级会直接跳过修复。v3将严重度与动作拆开：

| 动作 | 条件 | 结果 |
|---|---|---|
| repair_source | 明确原文支持修复 | 自动局部补丁，不受production标签影响 |
| repair_neutral | 仍不明确但可保留剧情并中性呈现 | 去掉无据确定性、落实明确声画方案；保留必要台词 |
| keep | 审核误判，或真正可选的表达风格 | 留下核验理由，不改正文 |
| blocked | 关键问题无法在不编造事实的前提下解决 | 自动失败，停止放行，不以等人工充当成功 |

代码禁止supported的production/blocking或事实/连续性/范围错误用keep放过，未决不能keep或伪装为有据修复。处理范围由核验节点重新对当前稿定位，可含多个位置。重叠范围按原文位置取并集，完整保留范围以外文本；错误地址不能模糊替换。

修复后定向检查所有已选问题，新观察含production继续流转；旧问题不会仅因新审核漏提就关闭。独立整稿审不接收旧审核结论，之后程序才合并未解决记录。最终完成门要求：绑定当前稿的独立审、问题记录闭合、没有留给人工的待确认文本。结论为text_contract_complete或具体auto_failed状态，不再以ready_for_primary_review作为成功出口。

“无需人工参与”表示流程能自动作出完成或失败决定，不表示每次模型生成必然合格。当前不触发媒体任务；主助手对真实测试的验收是质量评估，不是v3运行时必需节点。

## 原文检索与更正

程序从已获取原文查找，所有段落保留原文和稳定ID。先补齐所选完整章节之间至多两章、合计不超过10000字符的短缺口；再按问题主题加权的2—4字符词组检索，携带命中段落前后各两段，单轮最多新增36段。检索范围不超过目标章末；证据角色evidence_only不能当作新增剧情重演。词法检索不保证召回，没命中不等于全书无据。

真实数据回归发现：单用长意见匹配会被“孩子身上”等词带偏，遗漏第20章衣物送货说明。增加主题权重及完整章缺口补齐后，真实数据检索回归通过。

实际补证据后撤回此前部分判断：第18章“自己男人”及紧接袁军，支持两人伴侣关系；第17/18章提供便利店经营关系；第20章说明购买多套、孩子换好衣服及送货上门。不能再把夫妻关系本身或收到快递判为全书无据。原报告保留，另存PRIMARY_REVIEW_CORRECTION_CONTEXT.json。不因此放行仍有其他问题的旧稿。

本次继续同一第22—23章原生候选，不重生成作者稿。新作者提示已实现但本轮未实测。369—380共12次真实文本调用，MiniMax 9次、DeepSeek 3次，584,340已知tokens；累计380次、7,720,954已知tokens，pending=null，无新增未知。

2. `20261101_autonomous_revision_v3_address`：复用369，仅371重新核验。增加唯一的排版/逗号分号归一定位，保留原始字符；但返回两个问题ID错位，完整失败保留。

新增受限协议处理：问题ID作为Schema键；只有一个缺scopes、一个多scopes/item且内容可原样归位时才修复结构，严格复验其他字段。错误原生响应与归位证明均保留，不填造字段、不重发请求。原生失败376的本地接续已真实使用；同调用内自动归位分支用对应真实返回离线测试通过，没有再新增一次在线格式故障来验证。

范围定位只支持唯一精确匹配，或仅空白/逗号分号差异；数字、小数点、否定词等不同仍拒绝。结尾制作附录中的编号条目，可用完整编号与冒号前标签作为结构地址找回原始整行；不用于故事对白，不做模糊语义匹配。原请求引句和实际原稿范围分别保存。旧370/371/376失败不覆盖。

接续任务继承389调用上界，最后一次仅剩一轮返修，未重置两轮工程边界。所有本次运行均已结束，不使用剩余调用次数继续追求通过。

## 最终验收与边界

已验证：production问题不再跳过；缺前情先补原文；无据钥匙被删除；系统奖励因果恢复；七条待确认内容实际删除；未解决制作问题仍会自动阻止完成。运行时没有“等待人工确认”或主助手批准的必经节点。

尚未完成无人内容验收。最终模型仍提出：开场袁军上一句缺少可听衔接、叶西决第一人称心声残留“他们”指代、送货口径把已穿衣物也包含进袋内。主助手认可这些需要处理，但说明开场衔接要区分独立分段和接上集播放，心声叫苏墨名字本身不是人物关系错误。另外CH22-P025署名仍未明确核实，不能把无人工待办等同事实全正确。

本轮是**自动失败并保留结果**，不是把剩余问题转交用户填写，也不是全链无人生产通过。失败终态保持不变，主助手仅另存测试审查，不手改模型稿。默认网页/媒体流程仍未迁移，未生成视频、发布或重启服务。
