# 逐命题核对与未决问题追踪：开发和真实回归

## 实现

每条事实保留稳定ID；逐片记录主体、动作、对象、否定条件、信息来源及来源段ID。初版由模型拆原样跨度，实际出现省略标点和改词，最终将切句和编号交给程序。按标点生成片段ID，程序确保完整重组原句；模型只选编号判断。完整条目、完整原章仍在上下文。标点分片不保证一个片段恰好一个语义命题，仍要求模型检查其中所有限定。

旧问题和新问题都有稳定issue_id，修改建议不关闭问题。修改后的同稿复审须逐一回答未决项，并核对全部材料；只有无新错误、没有修改提案且确认resolved才关闭。独立内容检查验证替换的依据和信息保留，采用模型生成的局部替换，未改条目保持不变。
