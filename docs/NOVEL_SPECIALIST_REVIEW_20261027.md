# 三路专项审核实测（2026-10-27）

将审核拆为人物动作、否定条件、时间场景范围，三路读取同一候选SHA，提出指定事实的局部替换；独立检查替换是否有原文依据、是否保留正确信息，然后再次三路复审。原生材料不手改。对象为完整第9—10章及第8章上下文，接续先前两组材料，不是新的盲测。

首版反复出现引文抄错、跨章地址错，以及错误诊断阻止有据改写。v2让模型选原段ID，程序附完整原文（明确不是模型原生引文），并将诊断意见与替换内容检查分开：不认可原理由也可接受有据且信息保留的新表述；任何替换内容或保留性不确定仍拒绝。该机制只能证明地址存在，不能证明引用与主张有关。

## 实际结果

- 细粒度组：本轮累计13次，两轮局部修改、5份补丁采用。修复无据追求预设和拿碗筷对象；末轮仍把“此前担心”改成“同时仍担心”，原文不足以支持排他判断。因返修上限停止，不能称自动验收通过。
- 示例压缩组：本轮累计9次，一轮局部修改、3份补丁采用，邻章工资材料移入上下文；让座对象和“或许不是”改善。三路模型复审都通过，但主助手复核仍发现否定漏字（再不还钱→再还钱）、摆头→摆手、叙述变对白、碗筷对象无据、直接引语不准确。独立验收不通过。
- 冲突补丁按顺序采用首份并推迟其他提案，导致较完整修复被推迟，后续模型又漏报。需要将未解决的问题显式保留并重新绑定新事实，不能仅靠再次全文自审。
- 压缩长句混合多个动作、条件、叙述层级；列出全部fact_id并不等于逐个命题完成核对。下一步应先拆原子命题，针对主体/动作/否定/条件/信息来源逐项对照，再回装完整材料。否定词差异只能作为检查信号，不能机械改字。
