# H3 接续管理页

视频制作流程页优先读取已审核接续 PLAN 与运行回执，前 37 段使用 SHA 绑定的原分段，后续只显示已选 A0/A1 或原产物收存目录。服务 8190 与调度监护分别展示，显示心跳、进程身份、当前原任务 ID。播放或下载只选择已收存的 MP4。刷新无业务写入。

冻结执行器每次轮询检查 PAUSE.json（约 25 秒）；已经提交的本地 GPU 推理继续运行。暂停可能在已进入派发步骤时生效于下一次轮询。执行器将明确的 manual_pause 写为根 STATE blocked，单删 PAUSE 不能恢复。页面操作仅限已登录管理员。新暂停标记、计划 SHA 与唯一操作号写入审计；继续时只允许本页同一标记，等原执行器退出，在同一执行锁中将精确的 blocked/manual_pause 转回可接续状态，保留原任务和原 ID，归档标记与动作记录。其他任务失败、未知、外部暂停标记或完成状态保留。页面不提交媒体，后续由已登记的 Windows 调度监护处理。
