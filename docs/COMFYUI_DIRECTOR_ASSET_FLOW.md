# ComfyUI 导演资产层与 Seedance 分段执行

当前项目采用“角色身份卡 → 空景背景 → 场景构图草图 → 低重绘/局部修复首帧 → Seedance 分段视频”的混合流程。

## 资产门

1. 角色身份卡锁定年龄、脸型、发色、发型和服装。多人镜头先制作角色组合参考，不能由视频模型自行发明同框人物。
2. 背景图只允许空间、家具和固定道具，不得混入人物、标牌、伪文字或与剧本冲突的门窗。
3. 角色和背景先合成为构图草图，明确站位、景别、遮挡和道具归属。
4. IP-Adapter 只用于构图与风格探索；涉及人物数量、合同数量、包具归属等硬事实时，优先用低重绘 img2img。局部道具错误使用带遮罩 inpaint，不得整图重抽。
5. 每个首帧必须实际看图审核并绑定 SHA256；生成成功不等于通过。

## 道具归属门

- 外观相近的包具必须在颜色、轮廓和画面位置上明显区分。
- 角色从容器取物前，该容器必须已经在首帧内完整可见，并位于正确角色一侧。
- 提示词同时写明允许触碰的容器和禁止触碰的容器。
- 抽帧发现角色误拿其他人的包、合同合并/增殖或出现可读伪文字，当前段立即失败；只修上游首帧或动作提示，不能靠剪掉关键动作掩盖。

## 视频门

- Seedance 2.0 Mini 单段限制 4—15 秒。长镜头按语义拆分；2—3 秒过渡优先用经审核静帧加本地确定性镜头运动，或与同场景相邻动作合并。
- 每段保存请求预览、提交回执、原视频和原始尾帧。已有回执禁止重复提交。
- 每秒抽帧并检查首尾、人物、手、关键道具、刺激—反应时序与构图。
- 音轨必须同步核验。ASR、响度和频谱只能辅助判断，不能代替实际听音。音频未实际审核时状态为 visual_passed_audio_pending，原始尾帧不可释放给下一段。
- 新剧本失败计数从 0 开始；同稿重试累计，默认上限 10。
