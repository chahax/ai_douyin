## 规范补充

在既有人物近景、环境体现、对白动作神情交织、自然镜头衔接的基础上，补充：

1. 跨章接上章最后的发言、动作和情绪，不重复演整段前情。
2. 同一连续场景保持人物服装、伤势、持物及空间关系，分清现在、回忆、猜测和未来。
3. 先完整呈现剧情，再按自然动作/对白落点分段；不为15秒截断一句话或必要事件。
4. 区分小说事实与普通布景、表演设计；可以补合理微动作，不借此新增人物关系或事件结果。
5. 最近三章优先回看，近章承接优先于久远分析；本轮范围都在前三章，仍保留完整原文前缀，未验证更长篇的自动截窗/检索。

规范正文冻结到每个显式测试任务，作者、DeepSeek审核、核验、补丁、复核读取同一份。旧默认配置不启用该规则集。文档位置：`docs/VIDEO_SCRIPT_RULES_20261101.md`。
