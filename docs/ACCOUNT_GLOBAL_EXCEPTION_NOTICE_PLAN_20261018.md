# 账号异常在各页面展示人工处理提示（2026-10-18）

用户再次强调“有问题不是说前端显示人工处理吗”。现有持久异常与关闭功能在抖音账号的自动更新日志子页，其余页面不可见。本轮补全全局可见性，不恢复或重派账号任务。

登录完成后、页面内容之前插入独立15秒本地刷新区域，展示所有未关闭的账号异常（明确账号、待人工处理、原因、发生时间），即使正在其他账号/创作页面也不会漏掉后台待办。只读取本地持久异常，不访问平台或触发恢复。未登录不展示账号数据。

管理员可对具体异常人工确认并关闭；查看者只读。沿用既有close_account_issue记录，不改原任务结果，不清暂停、不确认登录有效、不永久屏蔽同类异常。新异常ID重新出现。提供进入抖音账号处理的页面链接；恢复仍须原环境人工处理与原身份核验。

原自动更新日志详情、关闭历史继续保留，按钮key与全局提示分开。全局无待办时不占页面；异常读取失败不能显示“无异常”，应提示状态暂不可用。

前端子agent实施独立组件与入口/测试，主agent审查认证位置、跨页面接线、关闭语义和离线回归；仅空闲重启部署并核对原暂停/原ID完整保留。实际浏览器未登录则如实记录，使用AppTest验证认证后渲染，不伪造用户登录。
