# MiniMax H3 本地低分辨率短片验证

用户在 ComfyUI 升级后明确要求：“先用低分辨率、约5秒短片验证加载、生成和音视频保存，再增加时长”。这是独立本地技术验证，不迁移旧创作任务、导演预算、媒体账本或审核批准，不调用付费云服务、文本模型或发布。

## 首次验证范围

复用已经下载并校验的 Comfy-Org 官方 H3 t2v 工作流与 v0.40.0 原生节点。目标 512×288、24 fps、124 帧（H3 原生 17k+5 网格，约 5.17 秒），batch=1。使用现有 FL2VA int8 主模型、对应 8-step turbo LoRA、Qwen3-VL NVFP4/AWQ 编码器及现有视频/音频 VAE。实际步数、采样器、sigma、CFG 以官方范例和实际 node schema 为准，不猜参数。

测试单镜：安静办公室内的木桌，一只手把杯子轻放桌面，轻微窗帘运动，伴随杯子落桌的轻响和室内环境声；无对白、音乐、字幕或可读文字。此内容只是加载、动态与联合音视频保存的技术小样，不声称走完法律剧情创作链。

全部新文件、模型缓存、CUDA/Torch/编译缓存、临时目录和输出放 D 盘。保留 C 盘既有 Python/ffmpeg 程序与既有模型路径配置，不向 C 盘下载。优先使用原生量化和卸载机制，按本地 16GB 显存/32GB RAM 保守配置；不未经证据安装实验性插件、重装 torch、改系统驱动或分页文件。

## 分工与派发

按项目先文档、子 agent 实施、主 agent 审查的要求：子 agent 先从已保存官方图和实际源码/schema 准备单个可恢复工作流、启动/提交/原 ID 查询脚本与参数说明；主 agent 审查实际接线与文件范围后执行本地短片。只允许一个 GPU 生成任务，不并发跑长片。

工作目录：`D:\IT\ai_douyin\data\local_media_tests\minimax_h3_20261015`。提交前保存完整输入、官方源哈希、实际图、模型文件身份与唯一运行 claim；成功取得 prompt_id 后只查询该 ID。结果未知、未决或失联不重新提交；技术失败保留回执，禁止脚本自动重试生成。

先完成约5秒的结果再决定增加时长；不使用未获用户批准的小样原尾帧续段。任何更长试验须沿用本次明确的顺序与审核边界，不把本地 smoke test 当作冻结故事的新额度。

用户在执行期间进一步明确：下一档选择“约15秒，接近H3常用时长上限”。因此，5秒技术验证成功后允许以同一工作流与原文本独立生成约15秒测试片；不把此答复解释为5秒内容已经通过，不用未批准尾帧。两份测试均保存为 awaiting_human_review，任一次技术失败或结果未知不自动重派。

## 验收与交付

1. 只读核对 core/node/schema、模型文件位置和安全的本地启动参数。
2. 从 ComfyUI 实际日志/history 核对编码器、主模型、VAE 加载及采样/保存任务是否成功。
3. 核对完整输出保存、文件大小/hash、容器与音视频流元数据；如保存独立音频，同样核对格式/时长。可用 ffprobe 读取容器/包信息，不做抽帧、听看、ASR、波形/响度分析或音画质量审核。
4. 视频一律 `awaiting_human_review`，技术状态独立记录；不写内容 passed。将原视频直接内嵌或链接给用户并给完整绝对路径。

本地 comfy CLI 不在 PATH 时先核实已有安装位置；没有实际可调用 CLI 时使用 ComfyUI 官方本地 HTTP API 作为兼容路径，不因此新增云服务或安装全套 CLI。

## 实际执行与主审结果

两阶段已在 RTX5070Ti 16GB / 32GB RAM 的 Windows 本机完成，ComfyUI v0.40.0，模型和全部输出在 D 盘。本地未发现可调用 comfy CLI，实际使用官方 localhost HTTP API。
