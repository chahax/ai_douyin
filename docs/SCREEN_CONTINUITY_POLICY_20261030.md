# 通用画面取舍与连续性规则试验

用户确认：出门等过渡可以合并或省略，不必逐动作生成镜头。固定小说地名补丁和逐词出处不能代替通用流程。

## 原因校正

当前入口一次生成完整章节剧本，不是逐场调用；此前“场次之间没传数据导致重新选地点”不是已证实原因。实际证据是：完整稿存在地点继承矛盾，旧格式检查只检查地点字段；后续原词出处校验又无法区分当前地点与计划/离开的地点。

本次采用通用规则：先区分实际、计划、回忆、猜测，再选择必须表现的信息；允许省略过渡，核对保留的画面是否仍与原文一致。分头行动分别看主体；新位置不确定时不补地理归属，可用不强调位置的近景。普通灯光、微动作仍允许。

实现为 screen_continuity 模块的作者/审查共同规则及独立对白正文诊断，接入 run_restricted_transcription 的同名试验入口。没有建立新自由摘要、全书位置库存或逐场状态引擎。旧 source_locations 试验保留，新入口使用普通地点描述，不强制地点词出处串。人物归属规则本次未修改。

## 程序与模型测试

- 24项回归通过：data/qa/screen_continuity_20261030.xml。包括重放上一稿38条空对白、有效对白通过、评分缺项/重复项、完整原文和同稿审核绑定、对照答案不外发与请求隔离。
- 预先冻结12条人工构造对照，涵盖出门省略、位置不强调、计划未执行、回忆、分头行动、无转场和错误地点归属。MiniMax逐条判断12/12正确，主助手复读理由均成立。只是短情形判断，不是其他小说真实生产或泛化验收。

## 真实小说结果

14场原生候选；出童装店后续写商场内，末场便利店不附商场或乐园归属；输出的38条对白均有正文。此前两项具体缺陷本次未复现。仍保留出门动作，不能据此声称已经自动优化所有无信息过渡。

整稿仍 needs_revision：海鲜心理感叹变出声对白；待核备注仍猜“哥哥中的一位”；开头未决应声与群体发声画面冲突；回忆心理仍混入画面栏。7项程序诊断属于归属引用/待核合同，不能一概算成7个剧情错误。

模型审核捕获部分问题，但仍有不成立的理由：唯一女孩不代表年龄最小；连问期间开始勾菜不必然与此前未点菜矛盾；导购前文“她/阿姨”不能被一个“他”推翻；参考摘录不配音不禁止正文采用同一原句。未照单修改或据审核自动放行。

结论：通用规则的短情形判断通过，真实小说地点承接局部改善；完整无人生产未通过。没有手改原生剧本、默认迁移、媒体调用、发布或服务重启。下一独立问题为表达通道与待核猜测，不再把这些问题归入地点规则。
