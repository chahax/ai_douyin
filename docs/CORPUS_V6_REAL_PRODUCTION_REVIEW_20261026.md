## 架构判断

本轮没有输入超限或输出截断证据：首请求 2,159 输入 tokens，模型配置上下文 65,536，两次均正常结束。不能把本次问题简单归因于“输入太多”。

直接观察到的是原文地址映射失败。当前请求给完整连续正文，另给只有 ID 和字符偏移的段落目录；对小模型而言，识别原段边界不够直观，这是可能的促成因素。返修只给通用错误，也未说明哪一项实际跨段。

此次“先分类、后细化”的职责拆分已生效：没有因为缺少位置、持物或知情数组而退回。来源门、一次返修上限及失败后停止也按预期工作。真实模型的材料产出尚未通过，不能因此宣称整条自动产稿流程成功。

优先改进：在保留完整章节语境的同时，让原段 ID 与正文位置直观对应；引用失败时返回具体字段、原段和跨段证据，再由模型自动修订。不得手改本轮候选后冒充模型成功。
