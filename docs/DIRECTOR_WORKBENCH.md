# 结构化提示词与 ComfyUI 导演台

第一版是可运行的本地提示词编排台：镜头卡 → 确定性编译 → 提示词及待审材料。没有连接付费视频节点，也不自动放行生成或审核。ComfyUI 是组织控制的界面，不能仅凭换界面保证 Seedance 的演技和画质提升。

## 使用

在项目根目录运行：

```powershell
.venv\Scripts\python.exe scripts/build_director_workbench.py config/director_card.example.json --output data/director_workbench/demo_v1
```

输出 `prompt.txt`、`review.pending.json`、可拖入 ComfyUI 的 `workflow.json` 及供 API 使用的 `workflow.api.json`。输出目录必须不存在，避免覆盖已审候选。示例是独立摄影练习，不是当前剧本的新稿登记或生产授权。

将 `custom_nodes/ai_douyin_director` 整个目录复制到实际使用的 ComfyUI 的 `custom_nodes` 下，重启 ComfyUI，再导入 `workflow.json`。无需下载模型或增加 Python 依赖。镜头卡各字段可直接编辑，运行后预览节点显示待审文本；API history 中也保留文本结果。仓库内已提供节点，安装和真实前端运行需要在目标 ComfyUI 验证。

## 导演写法

每镜明确三个层次：观众应察觉的变化、演员可执行的动作、摄影如何突出这一变化。不要只堆“电影感、情绪丰富、8K”。

| 控制 | 应写的内容 |
|---|---|
| 叙事意图 | 想得到什么、什么阻碍他、本镜改变什么 |
| 表演 | 情绪起点→触发→终点，以目光、呼吸、力度和节奏体现 |
| 构图 | 主体与负空间、景别、轴线；前中后景各自的用途 |
| 光线 | 有来源的主光、明暗层次、色温；保留眼睛和皮肤细节 |
| 运镜 | 一个主要运动、起止时刻及动机；没有动机就固定 |
| 声音 | 明确说话人、自然语速、重音和环境声；对白只写一次 |
| 连续性 | 首尾视线、手、道具位置；不重新上演已完成动作 |

先改善构图、光线和表演，再增加适量运动。景物丰富应服务剧情，不能为丰富而增加未经批准的道具。固定镜头也可以有情绪；每段都推镜或大幅换机位容易破坏空间和尾帧衔接。

## 与现有生产线衔接

1. 将已审剧本中的身份、对白、动作和首尾状态放入镜头卡，不直接修改已审核文件。摄影改变若与已锁定机位冲突，应回到上游摄影修订并重新审核。
2. 导出是候选，`text_review` 和 `media_review` 始终为 `pending`。结构校验只能检查必填项和时长，无法确认语义与锁稿一致，也不是模型演技评分。
3. 通过现有制作入口绑定真实来源、摄影修订及独立文字审核后，才使用审核后的提示词。此候选 JSON 不是现有生产接口的执行计划，不能直接冒充通过审核的文件。
4. 后段选择 `raw_tail_continuation`，但该选项不验证媒体链。实际原始尾帧、相邻片段审核及哈希仍由现有入口检查；不得用 ComfyUI 重绘图片替换原始尾帧。
5. 按 [视频制作流程](SCRIPT_VIDEO_RUN.md) 逐段生成并抽帧、同步听看，记录秒数与证据；通过后才能继续。新稿计数只通过既有登记入口重置。

建议第一次比较同一已审镜头的原提示与新摄影候选，分别记录主体清晰度、情绪变化是否可见、动作节奏、声画同步及尾态可接性。两者都经完整审核，实际观感优于旧版再扩展。此次实现不提交试片、不消耗生成额度。

节点采用 [ComfyUI 官方自定义节点接口](https://docs.comfy.org/custom-nodes/backend/server_overview)。
