# 创作与媒体能力接入：修改方向、分工与验收

用户要求：“记住你的整个修改方向可以先生成文档然后子agent修改你审查”。本文件先于子agent开发建立，作为本轮实施和主agent审查依据。环境及官方依据见[能力审计](CREATIVE_PROVIDER_ENVIRONMENT_AUDIT_20261012.md)。

## 固定方向

目标仍是可复用流程：法律标签/来源与简报 → 完整原生剧本与同源全文审查 → 整片导演 → 局部表演 → 确定性编译 → 全文制作复审与真实请求覆盖 → 用户审核视频。完整作品及交接是最终目标；离线样例和请求预览只是开发证据。

保留MiniMax-M3创作、DeepSeek少量文本审查、Ark Seedance 2.0 Mini视频与已有生图路线。先利用已核实能力，不换模型、不整体迁移开源平台、不继续把机械状态责任堆给提示词。

整片导演只决定情绪、因果、观察对象和叙事切点；端点合同由模型选终点/预算档，程序推导唯一连续起点与来源范围。局部表演决定当前台词、动作、反应的实际窗口；共享身份/空间/道具规格不可逐段重新发明，动态持物/位置/情绪单独传递。程序检查预算、状态前提、完整来源、素材编号、模型模式和实际请求覆盖；审查负责全文语义与制作可读性。

固定素材必须一一绑定角色ID、实际素材中的主体、原服务任务/原文件哈希、外貌服装与真实声音输入。选定图片进入导演的实际多模态请求；声线没有真实输入时如实标unbound。参考素材选择依当前段需要，不能把完整三视图、整片或无关素材一律塞进请求。

连续动作走明确批准原尾帧的正式首帧模式；重新入画、换机位和主体/声音参考需求可建立独立多模态模式。正式首帧与多参考互斥；多参考用提示词指定起帧不宣称正式首帧硬约束。同账号30天原生素材资格、24小时URL可访问性和实际视觉质量分开。

调度始终拆开提交、保存task ID、原ID查询、保存原视频/原尾帧、awaiting_human_review、人工批准。未知结果不重派；已知完整失败按现有有界整稿返修。工具正文不得手动转换成已验收工具结果。
