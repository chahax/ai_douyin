## 已确认缺陷及修复

1. 原浏览器 worker 超时退出后，resource 仍持有失效 session，账号 host 的窗口轮询继续 RPC 并崩溃，心跳停止。新增 `BrowserWorkerUnavailable` 和只读 worker 存活检查。只有原任务均有终态、无人工窗口及未知结果时才清理失效资源，下一项独立任务可建立新会话；不重跑原任务。67 项相关回归通过，包含真实本地 Chrome 的 worker 终止、同 profile 下一任务恢复。
2. 真实抖音搜索前端的 `.search-result-card` 是无链接 DIV，父节点包含 `waterfall_item_<video_id>`，旧提取器只找 `/video/` 链接。兼容新版卡片并更新加载与验证恢复的结果选择器；要求实际卡片、合法 ID、时长和作者，排除相关搜索；保留旧版与按 ID 去重。只在已有明确语义或已核对心形 SVG 时记点赞数。
3. 兼容可见日期中的前置圆点及中文年月日，不把无法解析日期编成当前时间。
4. 人工窗口在跳转超时后，对同一页、同目标、已提交且 readyState 可读的情况保留页面，继续独立观察验证码控件并进入 waiting_human。其余情况仍保留失败，不重导航、不当作身份核验成功。
5. 推荐流实际探测的 challenge_evidence 进入持久结果，避免只有“验证界面无法确认”而没有可检查的细节。
