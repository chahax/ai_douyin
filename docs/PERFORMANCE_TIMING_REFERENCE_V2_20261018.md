# 对白状态、发音量与反应排时 v2

本版替代新任务的v1参考；旧规范、稿件和请求保持原版本。上一版将“情绪被看见的时间”与“台词结束后的额外停留”放在同一列，又笼统地给情绪对白放慢，容易让普通确认占用过长时间。本版拆开核对。

这是项目拟采用的创作估时起点，不是行业统一标准或真实录音测量。每句实际字数可以核对，能否自然说完还要结合具体说法；文本估计不等于已经验证语速、口型或视频观感。

## 情绪通常随对白发生，台词后默认不留空窗

| 内容 | 需要发生变化时的可见窗口参考 | 台词后额外停留参考 |
| --- | --- | --- |
| 听懂关键信息、确认 | 0.3—0.7秒，优先在末句中显现 | 默认0；确需交接可约0.2—0.3秒 |
| 防备松开、愧疚显露、释然 | 0.4—1秒，可在听/说话中变化 | 默认0；有具体作用时约0.2—0.4秒 |
| 重要选择、压住泪意 | 若需表现变化，先按0.6—1.2秒估 | 默认0；确有表达需要约0.2—0.6秒 |
| 已经决定、眼中已有泪或情绪已经成立 | 直接展示当前状态 | 0秒，不再从中性脸重新演起 |

“可见窗口”不是人物整场只能带着该情绪这么久，而是让观众读到一次变化的参考。愧疚可以贯穿整句对白，眼中有泪也可以直接、连贯地说话；不能自动安排“先酝酿两秒，台词说完再反应两秒”。两列时间不固定相加，已经在对白里完成的变化不再演一次。

重大转折确实需要更长时，应写清新信息、尚未完成的选择以及镜头要让观众读到什么。超出表格不是程序失败；保留的时间必须有具体作用。反应不得早于刺激到达，也不能只为缩秒把尚未发生的理解提前。

## 对白要按说话方式核对，不按情绪名字一律放慢

| 说话状态 | 初始发音量参考 | 每个发音单位约用时 |
| --- | --- | --- |
| 平静说明、日常交流 | 3.5—4.5单位/秒 | 0.22—0.29秒 |
| 利落追问、直接回答 | 4—5单位/秒 | 0.20—0.25秒 |
| 认真强调、克制地承认 | 3—4单位/秒 | 0.25—0.33秒 |
| 带笑、眼中有泪，但仍连贯说话 | 3—4单位/秒 | 0.25—0.33秒 |
| 明确有声音哽咽、断句 | 2.5—3.5单位/秒 | 0.29—0.40秒 |

愧疚、低声、生气并不自动对应慢语速；选实际的说话方式。不要因眼里有泪就默认哽咽，也不因着急就让台词难以听清。

本稿以明确写出的汉字读法逐字计数，标点不计。数字、日期、字母、缩写与单位符号先展开为准备采用的读法，例如“3个月”明确成“三个月”；未明确读法时标为待确认，不假定完整时长。汉字数只是发音量代理，儿化、轻声和具体读法仍需调整，不能声称已测得真实音节数或声音时长。

## 每句分别确认声音和整个互动窗

内部核对表至少说清：原台词、说话人、说话状态、实际采用的发音文字、发音量、纯声音估时、真正需要的句内停连、接话间隙、同时进行的动作/听者反应、台词后尚需完成的内容及切出条件。这是工作检查项，不增加MiniMax工具或JSON交稿硬门。

纯声音参考：发音量÷语速。只有明确需要的停连才加一次，逗号和句号不自动各加固定停顿。整段互动窗还可能包含先后依赖，但“互动窗1.7秒”不能被理解为让4个字拖满1.7秒。

例如“票买好了”按本稿逐字计为4单位，直接回答可先估0.8—1秒声音；“我没问这个”5单位，可先估1—1.25秒。推票可以同时发生，女儿在听到支持并看到票后即时反应，不在两句后又分别追加一次凝视。若台词已结束而动作仍未完成，内部表要写明必要动作，不能用一个笼统的“情绪”说明多余时间。

若是10单位的克制承认，声音可先估2.5—3.33秒；不要机械拉成5秒，也不能为匹配参考值加速。实际语句的停连、信息密度、口音与表演仍需同稿审核和之后用户审片。

## 合并与审核

同一时间能发生的内容放在并行分支，先处理真实依赖和刺激到达时点，再取各分支最后完成的时刻。只有确实要在它之后发生的动作或关键反应再接上。末态不是另一个保持镜头。

内部可以保留小数估时和每句范围。Seedance Mini实际提示词用说话状态、动作先后、并行关系和明确收束表达，不发送小数时间表来强压字音。服务仍按既有整数档，创作者先核定段长，整理与SDK编译不私自改秒；不足最短段时合并内容，不增加无信息等待。

新规范完整副本和SHA随brief进入编剧、全文审核、自然导演、忠实整理和最终全部请求复审。估时辅助只报告参考与未知项，不按字数或区间自动给内容通过/失败；原硬范围、预算、未知请求、媒体人工审核和旧运行冻结继续保持。
