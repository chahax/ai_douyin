# 当前小说旧视频复用初筛与背景生成现状

建议保留小说、现有剧本文本、声音条目与所有原产物，从**人物和环境定版 → 本镜首图**重新制作新版视频，不沿旧85段继续盲续。旧视频并非文件损坏，主要问题是人物、场景、动作和字幕实现没有稳定遵循剧本。部分短镜头可以作为剪辑候选，尚未批准任何完整分段直接纳入新版。

本轮只读查看旧片和代码，新增文件均为QA抽帧/报告；没有模型或云调用、重新生成、删除视频、改变原暂停、重启服务或修改账号业务。

## 检查范围与方法

- H3正式交付 **85段 / 15分53.43秒**，逐段10%/50%/90%抽帧，共255帧，均与对应原文窗口比较。
- 每段交付及原生视频、FLAC、首尾PNG均核对原回执SHA，无缺件或不符。交付720×1280/24fps，原生736×1312/24fps；问题不在“分辨率数值不够高清”这一项。
- F0086另有已知成功的原生12.25秒视频、音频与首尾图；业务仍submitted，无交付receipt。另看3帧，不伪算成第86份交付。
- 同小说Seedance一分钟四段摘编另抽12帧，核对SHA。它不能代表119段完整正文。
- 173个原文unit的start:end与源稿全部逐字吻合；原文引用正确不代表视频演对。
- 未听音、未做ASR或全帧运动检测；有音频流不等于语言、台词、说话人和口型已通过。

## 背景是否在流程里

**有生成代码，当前这部小说没有已登记的正式环境图。** 正式资产库81条均为人物candidate，place=0；当前九人任务的packet `places=[]、shots=[]`，运行它也不会自动补出房间。

v3可以按剧本产生环境设计，调Klein生成无人正面净景、俯视布局图、实际镜头用到的反拍/侧拍，再审核并与人物组合首图。可是现场核查还发现：

1. 环境设计使用`layout_design`，正面审核却读取`appearance_design`，实际审核的环境设计描述为空。此处接线需要补齐。
2. 俯视布局目前是另一张模型图片，不是结构几何；它没有作为反拍/侧拍/首图的条件输入。只引用正面图和布局文字不能保证门、窗、床位置一致。
3. 既有5张房间试验图没有形成通过视觉验收的多机位环境集。
4. 现首图编译最多两位入镜人物加环境；六个孩子同桌等多人群戏还需可行的拆镜或扩展后的真实小样验证。

旧批次更没有独立背景资产生成：119段计划只有一张独立源图，即苏墨和两个孩子的卧室合照。全计划重复引用该图12次、引用生成尾帧120次，换场主要依靠文字要求。F0026/F0047/F0060/F0063/F0073等重建新场仍带这张合照，解释了卧室人物和房间被带到厨房的问题。不能仅凭引用方式断言每帧都错，但实际抽帧已经出现同类错误。

## 应从哪里继续

1. 保留小说、前三章完整稿、声音清单和原文索引；优先修制作输入，不重新编写全部剧情。
2. 先定人物造型，再建立前三章需要的同一套居所：苏墨卧室、孩子房、厨房及其中旧饭桌。固定门窗和家具位置，同一厨房的晚饭/早餐复用同一环境，仅改变时间、灯光和物件状态。后续门口、街巷、背巷另按真实场景补齐。
3. 补环境描述审核和布局/机位接线，验证同屋不同机位，而非继续无界重抽房间图。
4. 生成本镜首图，审核真实入镜者与空间；先验证跨卧室/厨房的短样片和多人吃饭的镜头安排，再批量替换旧画面。

最终结论是**从制作资产与首图阶段重新开始新版画面**。旧片、音轨与索引完整保留为素材和对照，避免将有用资料一起废弃，也避免将已经错乱的画面用补帧或放大继续加工。补帧、超分不能纠正错误人物、地点和剧情。
