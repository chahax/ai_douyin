# 创作者后台指标采集

## 2026-09-15 观看数据与生产改进扩展

看板包含播放、点赞、评论、转发/分享、收藏五项汇总及覆盖数量。每条作品保存追加式历史快照，支持单独查看累计、单日、指定区间数据，绘制计数/留存率趋势，并导出全部历史和原始指标 JSON。不能将不同统计区间相加当作累计数。

数据库升级为以下结构（迁移保留旧记录）：

| 表 | 内容 |
| --- | --- |
| creator_metric_snapshots | 原有计数和留存率；新增 avg_watch_seconds、total_watch_seconds、video_duration_seconds、watch_5s_rate、avg_watch_percent、unique_viewers、impression_count、profile_visit_count；保存 period、period_start、period_end、source_url |
| creator_metric_snapshots.metric_details_json | 流量来源、受众分布、逐秒留存及其他结构化详情，原始单位随数据保留 |
| creator_metric_snapshots.raw_metrics_json | 作品接口 statistics 原始对象，包括尚未标准化的新字段，不保存 Cookie 或整个接口响应 |
| video_learning_references | 按账号保存参考视频 URL、标题、推荐理由、时间点笔记、标签、学习状态；同账号同 URL 更新，不同账号隔离 |
| production_learning_experiments | 假设、具体生产改动、评价方法、数据快照 ID、参考视频 ID、基线/候选版本及当前结果 |
| production_learning_outcomes | 每次实验结果回填记录，保留历史决策 |

后台未返回值保持 NULL。新增观看字段代表已具备存储和分析能力，不代表已经自动获取。当前自动获取仍限于作品接口 statistics 和已匹配的内容管理卡片；详情页尚未自动遍历。运营看板“保存更多后台观看数据”可为现有作品追加详情，填入规范单位的指标和扩展原始数据。

“推荐学习视频与笔记”支持保存/更新链接、学习记录并导出。“生产流程改进实验”关联不可变的数据快照，记录对比方法和版本；同账号的视频制作页可查看实验及导出生产改进依据。新数据产生后可以回填结果、保留改动或不采用。保存实验不会自动生成视频或把未经验证的假设改成生产规则。

复盘提示只提出核查方向，不依据两条早期作品宣称因果关系。未来生产调整继续遵循逐段声画审核要求。

运营看板 `/page_dashboard` 增加按账号的内容表现区，支持即时采集、留存及互动指标、CSV 导出和页面文本证据。账号管理的普通链接及专属环境入口改为内容管理页。

自动流程：已绑定账号 → 运行租约/冷却检查 → 专属浏览器身份核验 → 作品列表接口 → 页面可见作品卡片 → 账号与作品关联 → 追加指标快照 → 看板读取。

命令行入口：

```powershell
.venv\Scripts\python.exe scripts/collect_creator_metrics.py --account account01 --pages 5
```

现有定时账号刷新调用 `DouyinAdapter.sync_videos`，因此也会保存指标快照，无需另设重复定时任务。既有常驻调度进程需在下一次正常重启后载入新代码。本次未重启或更改调度策略。

## 数据口径

- 播放、点赞、评论、分享、收藏来自作品接口或作品卡片，缺失指标为 NULL。
- 完播率、2 秒跳出率使用页面显示的百分数（21.43% 保存为 21.43），吸粉量为人数。
- 页面卡片以完整描述（允许前置短标题）及发布时间匹配；任意一侧存在歧义则不关联。不会按相近标题匹配。
- 页面结构依据 2026-09-14 实际 DOM：`video-card-info-`、`info-title-text-` 类名前缀。页面变化、卡片加载失败不会编造留存值。
- 当前只补充已渲染的卡片，尚未自动滚动加载全部作品。接口翻页范围以 `--pages` 为限，未见作品不删除。
- 留存指标与播放量可能更新不同步，不反推观看人数。少于 100 播放只作小样本提示，该值是应用提示阈值，不是平台质量标准。
- 暂未接入平均观看时长、流量来源、逐秒留存，也不以运营数据替代视频声画质量审核。
