## 分工与最小结构

1. 整片规划确定一次世界框架：时代及现实规则、行业／社会场域、空间关系、人物关系与处境、开场前已发生的事、观众情绪目标。已有角色／场景ID继续作为主体。世界设定、法律依据、用户要求、自选手段保持来源区别。
2. 每场原生正文有场次头：故事时间或相对时间、地点与环境、在场人物、与前场的关系、人物进入本场时的状态；时间跳跃和换地点明确。故事时间不冒充实际视频秒数。
3. 每段／拍覆盖所有当时在场人物的可表演行为与神情、刺激来源及反应。说话人的动作、听者的反应可与对白同时发生；保持或安静聆听也是状态，不为满足字段机械加动作。场次、拍和实际视频分段保持显式映射，不互相冒充。
4. 局部表演在全片世界、当前场次及前后事件中安排窗口；确定性编译检查主体身份、时间关系和状态承接，并整理文档。编译不创作新台词、神情或过渡，不把摘要当成已演事件。
5. 最终可读剧本先展示世界框架和人物关系，再按场次展示时间／内外景／地点／人物／承接、对白与并行表演。每个后续生成段实际收到同源共享信息及当前情境，不能只写素材文件名或孤立动作指令。

## 接入要求

先由子agent核对现有合同／目录／编译／审查／渲染哪些字段已支持，提出最小独立新版本，主agent确认后实施；旧v23、v26、v27和已冻结回执不改。新增世界和场次正文必须进入实际模型请求、全文证据目录与完整审查，不能只做展示层标题。原生版本与私有兼容检查投影明确区分。

世界和场次信息尽量只保留一份规范来源，下游按明确身份承接；不再创建相同事实的多套自由解释表。可复用既有字段时说明实际来源，缺失信息由生成模型完整提交，不手工补定时／角色动作。
