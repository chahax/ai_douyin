# 上传流程状态与异常修复

本轮核对：账号信息自动更新存在一条旧零作品结论的复核记录，已保留原回执并追加修正。新接口验证逻辑下再次补跑 completed，登录健康、零作品零评论；没有新失败。没有发现两条成片的项目上传回执，因此不能称其上传成功。

已修改：

- 上传日志在浏览器启动和登录检查前建立；登录失败、上传未确认完成亦写终态。
- 每次记录阶段同时写状态快照，历史 JSONL 保留。步骤包括检查登录、上传中、上传完成、填写完成、开始提交、待审核、作品 ID、异常与未知结果。
- 提交后的异常保留 submission_unknown 和防重复锁；外层服务、数据库状态及返回对象保留原状态，不再降级为普通 failed。
- 上传开始前本地作品标记 uploading，不能提前当作平台审核中。
- 指定封面入口缺失、非默认可见性设置失败时停止发布。
- 交互模式下仅按回车不再足以证明提交成功，缺证据仍返回未知。
- 作品库增加按账号显示的上传/发布回执表；无回执明确显示暂无，不编造成功记录。

验证：12 项上传状态与多账号测试通过；实际网页依赖环境的回执面板渲染通过。确认网页服务空闲后重启，健康检查通过。

限制：本轮没有执行实际上传或发布，也未完成平台动态界面端到端验收。上传完成标识、封面、标签、可见性等仍须在真实上传中检查；有作品 ID 和平台已接受不等于公开审核通过。现有未知提交锁保留，后续先核对平台作品/草稿再决定是否重新上传。
