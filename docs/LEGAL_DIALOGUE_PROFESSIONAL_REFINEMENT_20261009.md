## 七项检查标准

| 专业概念 | 本片要检查的问题 | 不能机械化的部分 |
|---|---|---|
| 口语语体与语体一致性 | 人物当面能否说懂自己的诉求，HR和员工语言是否符合身份；名词化是否遮蔽动机 | 长句或职场用语本身不等于AI味 |
| 话轮衔接与序列关联 | 下一轮在回应什么问题、压力或回避 | 允许不答而递纸、沉默和反问，不要求每问必答 |
| 言语行为与潜台词 | 通知、质问、施压、求情、拒绝和退出想改变什么 | 不强迫角色把动机全说破，不补“我理解你”模板 |
| 信息增量与功能性复现 | 同一事实再说时，压力对象或关系是否变化 | 不按重复字词计数判坏，不要求每句新事实 |
| 情绪递进与刺激反应 | 看清字样、听公司口径、听私人求情各引起什么变化 | 不强制哭泣或一路升级；可从急切转坚定 |
| 动作经济性与可演性 | 动作是否表现信息、关系、状态或反应；主反应是否清楚 | 同步自然信号可保留，不串行叠小动作和等待 |
| 指代清晰与物理因果 | 谁在什么时段碰、移动什么，目的地与持有是否成立 | 指代歧义不伪报已知持有矛盾，移动纸不证明手触笔 |
