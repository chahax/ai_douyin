> 备选：ChatTTS 开源模型支持更细粒度的情绪控制（笑声、停顿），但安装复杂。

### 手机UI合成

用 HTML/CSS 渲染每一帧的手机界面（短信、转账、好友申请等），然后用 headless browser 截图 → 作为 overlay 叠到 ComfyUI 生成的视频上：

```
HTML模板 → Playwright截图 → PNG序列 → ffmpeg overlay → 最终视频
```

需要4-5个UI模板：
1. 短信列表 + 诈骗短信
2. 微信好友申请 + 聊天界面
3. 转账成功通知
4. "进阶用户"系统消息
5. ¥50000转账确认界面（**全片最关键画面**）

### 片头钩子设计（关键——决定前3秒留存率）

参考视频的片头用了 3 秒黑底白字 **"我怎么会受骗呢"**，这不是随便写的标题，而是一个精心设计的**心理钩子**。拆解它的结构：

```
┌─────────────────────────────────────────────┐
│ 钩子结构（不是具体文案，是可复用的公式）       │
├─────────────────────────────────────────────┤
│ 1. 主人公的内心独白（非旁白，非标题）          │
│    → 观众在0.5秒内代入：对，换我也不会被骗      │
│ 2. 这句话隐含着"自信"——但视频接下来90秒要做的   │
│    就是一层层拆掉这份自信                       │
│ 3. 制造戏剧性反讽：观众知道标题是反语，         │
│    但角色不知道——看着角色一步步走进陷阱          │
└─────────────────────────────────────────────┘
```

**通用公式**（不要套用原句，套用结构）：

| 要素 | 说明 | 示例（可替换） |
|------|------|--------------|
| 视角 | 第一人称内心独白，不是第三人称描述 | ❌ "大学生遭遇刷单诈骗" ✅ "我怎么会被骗呢" |
| 情绪 | **自信 / 不以为然 / 觉得与自己无关** | "这种事轮不到我" / "我又不傻" / "就试试嘛" |
| 反讽 | 片头这句话和片尾结局形成180°对照 | 片头"不会受骗" → 片尾"我被骗了" → 观众：我也是这么想的… |
| 信息量 | 不剧透，不留关键词 | ❌ "刷单诈骗警示片" ✅ 什么都不解释，靠悬念驱动 |

**视觉执行**（极低成本、极高冲击）：
- 黑底 → 白字逐字淡入（每个字间隔0.3秒）→ 停留0.5秒 → 硬切第一幕
- 不加BGM、不加特效、不加logo——留白本身就是设计语言
- 字体：思源黑体 Medium，字间距 +200

**常见反面做法**（为什么无效）：
- ❌ "反诈宣传片——刷单诈骗案例" → 说教感，观众0.5秒划走
- ❌ "警惕！新型网络诈骗" → 新闻标题式，没有代入感
- ❌ 直接放受害者哭泣画面 → 过早泄底，悬念归零

## 七、分镜技术细节（逐幕）

### S1 诱饵上钩（15s）
```
镜头1 (3s): 男主看手机 → SDXL keyframe + Wan I2V: "guy looking at phone, indoor, night"
镜头2 (4s): 手机屏幕特写：短信内容 → UI合成（静帧）  
镜头3 (4s): 男主表情变化：好奇 → 犹豫 → SDXL keyframe: facial close-up
镜头4 (4s): "杰然不同"好友申请弹窗 → UI合成 + 男主反应
```
**关键点**：手机屏幕上的文字要清晰可读，不能是AI生成的乱码。

### S4 虚荣膨胀（18s）—— 最难幕
```
镜头1 (6s): 鞋店试鞋 → SDXL keyframe: "shoe store interior, anime style"
镜头2 (6s): 餐厅请客 → SDXL keyframe: "restaurant, friends eating, warm lighting"
镜头3 (6s): 公园长椅吹牛 → SDXL keyframe: "park bench, afternoon, casual"
```
**关键点**：3个不同场景 → 每个都需要独立的关键帧 + 一致的男主形象（L2角色LoRA的核心考验）。

### S5 大额收割（20s）—— 情感最高潮
```
镜头1 (5s): 手机屏幕：¥50,000 转账确认 → UI合成（红色按钮，视觉冲击）
镜头2 (5s): 男主打电话借钱 → SDXL + Wan I2V: "phone call, worried expression"
镜头3 (5s): 给妈妈打电话编造理由 → SDXL keyframe: "lying on phone, guilty expression"  
镜头4 (5s): 手指按下"确认转账" → 手部特写 + UI合成（全片最关键单帧）
```
