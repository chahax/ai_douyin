## 1. 重新分析后的结论

原片的观感并不依赖“全片只有三个稳定角色”，而是依赖两种不同的一致性：

1. **世界观一致**：所有镜头共享电影级光照、清楚的人物表演、手机作为视觉母题、冷暖色反差和快速硬切。
2. **角色各自一致**：核心女骗子、男操盘手只需要在自己的镜头组内保持身份；街头朋友、多个受害者、消费场所人物、泳池宾客和警员必须长得明显不同。

上一版的问题是把“同一画风”误做成了“所有人物共用相近的脸型、眼睛、年龄和服装气质”。新版本保留 3D 成人动画画风，但取消全片共享的人脸参考。角色差异通过脸型、年龄、发型、体型、主色和动作节奏共同建立。

原片真正的情绪链为：

> 街头炫耀收款 → 揭开多机工作室 → 情感话术流水线 → 多名受害者真心转账 → 造假生病素材 → 批量到账 → 赃款挥霍 → 受害者求还钱 → 夜湖落水 → 警方抓捕 → 老人拨号无人回应。

夜湖段涉及疑似轻生情节。改编版只用“湖边背影、巨大水花、空水面、湿手机”表达后果，不展示起跳动作、正面身体坠落或伤亡细节，避免猎奇化。

### 身份生成硬规则

- 每个核心角色有独立母版、独立参考图和独立 seed 区间；禁止用女主母版生成朋友、店员或其他女性。
- 共享的只有材质、渲染、镜头语言和色彩，不共享脸型提示词。
- 女主可以在工作室、消费段换服装，但必须保持心形脸、双丸子头/辫子和星形发夹；男操盘手保持窄长脸、乱金发和黑色主色。
- 三名受害者必须同时满足“不同脸型、不同发型、不同服装、不同室内环境”。
- 泳池宾客和警员采用分层合成，不能由模型从核心角色参考图扩展出“同一张脸的群众”。

## 6. 声音设计

- 0–35 秒：夜街音乐逐渐被多部手机提示音接管；工作室提示音密集但每一声有方向感。
- 35–48 秒：受害者语音保持近、暖、干净；骗子一侧保留薯片、滑屏和椅轮声音，形成冷漠反差。
- 48–62 秒：快门、发送、到账形成节奏组；不使用旁白解释造假流程。
- 62–78 秒：消费段音乐明亮、饱和；支付音和杯碰声作为剪辑点。
- 78 秒开始：泳池音乐先闷掉再完全消失；夜湖只保留风、水和低频。
- 83 秒警笛和撞门声接管；90 秒后进入低噪房间，最后保留忙音和陈叔呼吸。
- 台词与动作采用 J-cut/L-cut：先听见下一场声音，再切画面，保持剧情连续。

## 7. 生成路线

1. **先做角色差异联系表**：九类角色分别生成母版，检查脸型、年龄、发型、体型和服装是否可一眼区分。
2. **先做 8 个表演基准**：`001` 三人行走、`015` 笑容消失、`017` 推椅坐下、`032–036` 假病拍摄、`039` 到账庆祝、`049` 泳池多人、`058–060` 抓捕、`064` 尾声。
3. **手机屏幕不交给扩散模型**：生成阶段只保留稳定亮屏平面；金额、聊天、新闻和失败标记全部跟踪合成。
4. **工作流分配**：面部近景优先 LTX/LivePortrait；全身行走与抓捕优先 Move/ATI；多人场景分层；UI 和证物镜确定性合成。
5. **通过基准再批量**：任一高难基准未通过，不启动 104 秒全片生成。

## 8. 审核门禁

- 核心女骗子与街头朋友不得出现同脸；男操盘手、警员和受害者不得共享脸部结构。
- 同一核心角色跨镜头身份稳定，但服装变化必须有场景动机。
- 每个镜头只承担一个主动作；不得无原因半蹲、看手表、挥手或增加道具。
- 活跃手机屏幕从首帧到末帧保持亮；证物和失联手机可以按剧情保持黑屏或破裂。
- 三人行走必须有连续腿部动作；泳池宾客各自运动，不能同步；抓捕必须能看出每人的重心和进入方向。
- 任何镜头出现伪文字、手指融合、手机增减、人物变脸或背景重构，直接退回重做。
- 夜湖不展示具体轻生动作和伤亡；以声音、涟漪和湿手机表达后果。
- 完整候选必须 1.0 倍速人工观看；机器无黑帧、无长冻结只算技术通过，不等于观感通过。

## 9. 本版与上一版的根本差异

- 上一版：24 个长镜头、四个角色母版、女主参考影响了大量女性与场景，导致人物同质化。
- 本版：64 个剪辑单元、实际 69 个生成片段、至少九类角色母版；每个角色只锁自己的镜头组，群众不做身份锁定。
- 上一版：主要靠旁白说明剧情。
- 本版：对白、手机、手部、反应、消费和抓捕共同推进，不用背景介绍替代表演。
- 上一版：弱化了夜湖和尾声的因果。
- 本版：明确“求还钱→无人回应→夜湖后果→抓捕→老人拨号”的情绪落点。
