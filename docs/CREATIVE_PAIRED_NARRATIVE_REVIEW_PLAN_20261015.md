# 跨表述叙事一致性：第10轮实施设计

## 问题证据

627规划和634正文里，人物表示带走协商解除提议，最终动作却让经理把同一提议留在桌上，没有阻止、反悔或改变意图的过渡。631已有寻找反证的提示，仍同时引用相反描述并通过。独立报告见 data/qa/creative_scoped_text_session_20261015/INDEPENDENT_NATIVE627_CONTENT_REVIEW_v1.json 和 INDEPENDENT_NATIVE634_CONTENT_FOLLOWUP_v1.json。

因此本轮改变比较与证据承接的结构，不再仅追加同义提示。问题不能用“意图必定成功”规则解决：有意的受阻、反悔、失败结尾都应允许，前提是原文确实演出且后续解释不偷换成已成功。

## 独立模块边界

新增纯模块 creative_paired_narrative_review_v1，编译每拍及ending必须回答的比较目标。完整原文只保留一份无损视图，目标仅引用真实字段路径和引用编号。模型在原有drama调用中提交每目标唯一记录：各表述实际含义、意图/条件/已完成状态、同一对象及施事、支持与相反原句、变化依据及结论。比较结论派生总状态，不另置可互相矛盾的同义总评。

程序校验完整覆盖、精确引用、同源身份、明确声明的状态和未解反证；不按中文关键词猜剧情，不称确定性证明自然语言真伪。所有fail/unknown在正文前阻断。

已通过的原生比较记录及其目标、goal/context/bundle SHA须进入正文实际请求，全文语义包逐目标对正文真实steps再次比对。延续原有drama和全文语义调用，不新增独立付费审查层，不固定本片台词或结尾。当前634只作为回放和负例材料，不手改原稿或旧审查。

## 实施与验收

子agent新增独立模块与测试；根代理审查它与第9轮v5统一全文审查协议的接线。冻结v25/Session3与旧合同不改。覆盖：真实矛盾证据、意图达成、明确受阻、明确放弃、不同对象、引用归属、无关物件、主体倒置、完整结尾目标、漏项、假引文、引用其他稿、未知状态及pass隐藏反证。语义真伪仍须后续真实接口对照，离线仅验证合同和阻断路径。
