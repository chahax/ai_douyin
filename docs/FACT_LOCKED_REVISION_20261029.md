# 固定事实与受限表演试验

本轮按用户同意的方向修复：人物年龄不再靠排序推测，关键对白和说话人绑定原文，人物位置由现有连续性校验承接。实现为 `novel_adaptation/fact_locked_scene.py`，独立入口 `scripts/run_fact_locked_revision.py`，没有迁移生产默认。

## 验证结果及限制

- 39项相关程序回归通过，记录 `data/qa/fact_locked_final.xml`。
- 真实MiniMax 3次、11079 reported tokens；累计260次、5122878已知tokens，pending=null。旧135未知调用及消耗未知标记保留。
- 三场：首集开场、第7集赵雪转述、第55章树下私语。主助手逐项核对原句、说话人、角色位置；生成独立场景审查与承接记录。缺少其余场景时不能放行整集。
- 本轮人物表和事实卡由主助手核对；模型只选择枚举语气与简单动作。不是自动抽取、自由编剧或69章整链验收。
- 第55章此前参与过全书生产，仅未用于本路线调参；不是全新小说盲测。

## 局部修订

首轮替换整个人物标题，顺带删去动作描述，已保留该结果但不作为推荐稿。随后复用固定跨度工具，只删除3处无据年龄字段，周围描述逐字保留。最新文件 `第1集_年龄定点修正版_其他内容待审.md`。这是程序按已核资料修订，不冒称模型生成。

第7集将错误称谓、无据楼下住所及楼道往事所在段替换为原文“赵雪把昨晚发生的事告诉给余正华。”。模型选择“不追加动作”。保留其余正文，不代表相邻对白已审核。

全部证据位于 `data/corpus_production_trials/20261029_fact_locked_revision`，真实请求为REQUEST_258/259/260，原生返回保留。执行后入口和模块追加了年龄字段粒度修复，旧PLAN实现哈希保持原值；该任务已结束不可用新代码重跑。
