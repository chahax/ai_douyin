# 多账号改造分析

2026-09-14。范围：代码审阅与已有结构核对；本轮不修改业务、不新增账号、不执行发布。尚未用两个真实账号做完整隔离验收。

## 结论

项目有多账号基础，但目前属于“部分业务按账号运行”。需要打通账号上下文、数据归属、执行身份和统计口径，不需要推倒重写。仅增加下拉框不能完成多账号管理。

## 已有能力

- 运营账号有稳定 UUID、账号标识、独立策略版本。
- 真实抖音身份与浏览器环境一对一绑定；数据库阻止身份、环境重复分配。
- AccountRuntimeService 按账号创建会话并验证身份；DouyinAdapter.for_account 可按账号执行，发布入口强制验证身份。
- 作品页、评论页、回复建议已分别选择账号；作品和评论服务支持账号筛选，评论通过所属作品关联账号。
- 选题与剧本的部分服务已携带 account_uuid，并检查选题与账号一致性。
- 维护服务已有按账号的执行约束；发布工作流已有“账号标识 + 视频摘要”的防重复提交记录。

这些能力应复用。已有身份验证不等于所有入口都完成数据隔离，已有局部锁不等于所有账号操作共用统一锁。

| P0 | 换绑后的历史 | 运营账号 UUID 不变，但可更换真实抖音身份 | 保存绑定版本与历史；既有作品、发布回执冻结当时身份，换绑不把旧身份数据转给新身份 |
| P0 | 全局账号上下文 | 账号、作品、评论、回复页面各自保存选择，首页仍全局统计 | 建立统一当前账号选择；页面顶部持续显示昵称/抖音号；“全部账号”只用于明确标注的汇总查看 |

## 两类“账号”必须分开

抖音账号决定作品发布到哪里；火山引擎等供应商的计费账户决定由谁付费。多个抖音号可以共用一个 API 计费账户。

因此应展示：供应商账户的公共余额、每个抖音号归属的生成用量/费用、每个号的可选内部预算。不能把公共余额复制成每个号的独立可用余额，也不能将内部预算称为官方余额。不要求每个抖音号单独购买模型 API。

## 推荐的数据关系

后台用户授权 → 运营账号 UUID → 平台绑定版本与专属环境。

运营账号 UUID → 内容项目 → 剧本稿次 → 生成尝试 → 审核 → 成片 → 发布任务。

生成尝试同时关联供应商计费账户；发布任务同时记录平台身份快照。策略修改产生新版本，历史任务继续使用原版本，不能跟随当前页面选择变化。

## 老数据怎么处理

1. 先盘点所有缺少账号字段的作品、项目、报告与发布记录。
2. 优先通过原剧本审计、选题 ID、生成关联或发布身份回执回填，记录证据和迁移批次。
3. 没有证据的放入“历史未归属”；即便目前只有一个账号，也不能直接全部归给它。
4. 当前新建索引先支持兼容读取；确认迁移后再对新任务强制账号必填。原始回执不删除、不改写。

## 实施顺序

第一批：明确新增与换绑流程、全局账号选择、修复作品归属覆盖/同名匹配、制作任务强制账号上下文。

第二批：项目与用量筛选、发布身份快照、后台任务冻结账号、统一环境锁、专属浏览器管理入口。

第三批：按用户授权账号、内部预算、停用恢复、历史数据迁移与账号运营对比。

建议先完成第一批和发布安全相关项，再让第二个真实账号执行正式发布。可以先添加账号验证登录，不必等待所有报表完成。

## 验收场景

- A、B 两个账号同标题、同一视频文件，都保留各自独立作品/发布记录，不覆盖归属。
- 任务在 A 下创建后，即使前端切到 B、页面刷新或后台重启，仍只按冻结的 A 执行。
- A 登录过期不影响 B；A 的会话被切换成 B 时，A 的发布被阻止。
- A 换绑后旧发布记录仍指向旧平台身份，未决任务不直接在新身份下续跑。
- A 的作品/评论/剧本不能出现在 B 的业务操作列表；全账号汇总明确标注。
- 同账号两个任务抢占同一环境时有序执行；不同账号不共享 Cookie 或浏览器目录。
- API 调用能追溯所属账号和项目；共用余额不重复计数，未归属费用不伪装为零。
- 无账号权限的后台用户即使直接调用服务，也不能修改或发布该账号内容。

`src/operations_accounts/models.py`、`repository.py`、`runtime.py`：身份、环境、唯一性和运行上下文。

`src/services/video_service.py`、`comment_service.py`、`database.py`：账号过滤、归属写入和旧记录匹配。

`src/web/app.py`、`studio_home.py`、`video_production_dashboard.py`：分散选择器、全局首页统计和制作入口。

`src/services/production_registry.py`、`seedance_usage_service.py`、`scripts/run_script_video.py`：项目归组与生成用量链路。

`src/trend_intelligence/pre_video_script.py`、`opportunity/scripts.py`：已有剧本账号上下文。

`src/scheduler/models.py`、`src/web/components/auth.py`：通用任务参数和当前角色模型。
