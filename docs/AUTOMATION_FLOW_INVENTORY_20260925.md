# 项目自动化流程清单

更新日期：2026-09-25

## 状态口径

- **A｜真实跑通**：工程实现、测试及至少一次真实输入运行均有回执。
- **B｜工程完成**：代码、入口和自动化测试已完成，但真实平台页面、登录、验证码、外部模型或业务门槛可能阻止单次运行。
- **C｜受控 MVP**：可以运行，仍依赖人工登录、页面结构或单机执行环境，不作为无人值守生产承诺。
- **停用**：历史代码可能仍在仓库中，但当前正式注册表拒绝生产调用。

“已注册技能”不自动等于真实平台闭环已验收；“文本或本地测试通过”也不等于视频生成、发布或平台审核通过。
