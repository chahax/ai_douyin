# 自然对白与并行表演修订（2026-10-10）

用户反馈：语速过快，希望说话、动作和表情同时发生，整体更紧凑；当前剧本不像电视剧情，专业感不足。反馈绑定362稿的14秒首样，未批准继续其尾帧。助手没有看听视频。

## 核对实际原因

- 请求明确要求“稍快”，34个发音字按4.7字/秒排为7.3秒。这是项目主动配置；实际语速没有测量，过快判断来自用户。
- 句中小林的反应已写入，但2秒起态、1.5秒话后反应、2秒推纸、1秒移视和说话严格串行；不能把问题说成所有表情都在话后。
- 14/13.8的time_scale为轻微放宽，不是视频倍速。真正问题是对白估时与叙事组织。
- 文本首句承担公司决定、工作结束、手续备好、看表四项说明；后面反复说明不是主动离开。情绪多用眉眼肩线结果描述，缺少对对方采取什么行动的明确目的。

专业标准采用已有《画面、剧情与情绪表达标准》的功能：人物目标、策略及策略失败；自然应答；信息变化；刺激引起可见反应；行为推动关系。不是多堆术语、微表情或秒数，也不把电视剧质感当本地可自动证明的结果。

## 最小修改分工

1. 编剧提交完整新稿，保持同一故事事实。让周姐催办、避答、换私人请求，小林追问、回应具体理由、顶住请求；每轮回应上一句话，减少重复解释。所有实际发言保留独立dialogue项，动作说明不能藏一整句对白。
2. 导演确定每个交互的主观察对象、双方目标与刺激，允许对白期间观察听者；初态作为持续背景，关键转折才留独占反应。固定单机位不作为通用审美硬要求。
3. 局部表演明确对白、源动作和听者反应的起点。说话可配动作，表情可随消息变化；只有当前原文/导演明确允许的动作才能并行。纸到位后才能读字，重大消息尚未说出时不能提前演出理解。
4. 确定性编译验证独立轨和显式前提，计算最大结束时间；不把所有轨时长相加，不为15秒缩放说话。当前新模块仅离线验证，未接生产默认。
5. 完整新稿全文复审后，由用户核对内容，再重建导演/并行表演与样片；真实语速、演技和情绪仍由用户审核。
