## 自动语义裁决与责任返修

审核revise后使用独立MiniMax请求逐条裁决，候选SHA、审核SHA、意见序号与来源地址必须一致。只有upheld意见触发返修：materials定位来源章，bible定位包含相关章的归并节点，outline返回总纲，episode返回本集剧情，staging按候选路径定位当前场或本集调度。

每次输入包含经裁决的修正要求；输入变化导致阶段请求键变化，下游按实际新输入重新生成/复审。相同输入复用原生回执并重新做程序校验，不重派模型。每任务最多两轮语义返修，续写不重置该计数或调用上界。

失效时立即撤下产物索引中的旧派生产物，原文件仍在attempts目录留存。新审核绑定新候选，不能拿旧终审覆盖改后剧本。

审核不确定、裁决证据不足、意见全部被驳回、责任目标无法定位或返修达到上界时留证停止，不把“意见被驳回”自动当作剧本通过。裁决正确性仍需要真实模型及独立审查。

## 暂停、续写和重复启动

操作系统文件锁限制同一run同时执行，进程退出会释放锁。请求索引在HTTP之前落盘，缓存核对原请求消息、schema、角色、原生响应、模型、完成原因及候选校验；不采纳手改缓存稿。

可恢复状态为running且无未决请求、paused、ready_for_next_batch。未知调用、needs_attention及全部完成的任务不能盲重派。若收到响应但尚未完成安全记账，pending仍在，恢复会停住而不是重发。

暂停在当前请求结束、下一个阶段派发前生效。继续使用同一run、冻结授权、总调用计数和原生响应。每批集数是增量：先完成前两集，下一批接第三、四集；总纲与章节分析按相同输入复用，前集结束状态继续承接。每次尝试都有独立派生产物目录和结果快照，RESULT.json仅为最新状态镜像。

CLI续写：

```powershell
.venv/Scripts/python.exe -X utf8 scripts/run_serial_story.py execute --run <已授权v2任务目录> --resume
```

CLI拒绝未知冻结版本，也不为v1提供伪续写。

## 资产与网页

侧栏新增“连载剧本”，路由 `/serial-story`，沿用editor权限。可建立本地计划、展示书籍/章节/模型目的地与调用边界后明确授权、隐藏启动文本worker、暂停/继续、查看和下载产物。渲染页面本身不授予外发权限、不启动模型。worker再次校验授权、冻结实现和执行锁。

新增书籍隔离的本地图片版本库：人物/地点ID、方位、asset_id、version、文件SHA。导入同一对象同一视角产生新版本，旧文件不覆盖；绑定时必须选择明确版本，不允许同一视角混用两个版本。镜头必须覆盖所有在场人物及地点；跨书资产、变更文件、错误片段候选被拒绝。绑定导出保留人物/场景参考与各片段状态，尚不调用图片或视频生成器。

网页通过Streamlit AppTest无副作用渲染测试；本轮未登录并操作线上账号页面，也未重启部署服务。是否已被正在运行的网页热加载不作为本次验收结论。

## 验收边界

本轮完成上述代码与离线功能测试。完整生产验收仍需明确批准真实小说向MiniMax/DeepSeek外发后运行，独立审查新产物；没有使用合成故事结果冒充小说结果。

资产接入是已有图片的版本管理和镜头参考绑定；自动生成多视角图片、视频模型派发、成片与发布不在本轮执行范围。全文容量过大仍会显式停止，不裁切原章或通过放宽容量门掩盖问题。
