## 新独立入口

`scripts/run_creative_shared_full_production_v1.py`：完整新稿 → 同源全文复审 → 共用 manifest → 全片导演 → 各段实际表演与状态变化来源 → 确定性全片编译 → 全部文本制作复审 → 新首段视频。

`src/content_factory/creative_shared_production_contract_v1.py`：身份来源、批准资产对应、场景与道具规格、当前状态、平台输入模式、实际请求投影覆盖。角色档案缺字段或批准映射缺失时，不放行正式续段。

`src/content_factory/creative_complete_production_pipeline_v1.py`：所有来源按原顺序各归属一次；模型提交切点、演法和变化证据，程序派生 SHA、来源归属、排时、状态承接和视频文本。对白按3.3发音字/秒估计，不缩句或提速压时；每段4–15秒、整片最多180秒。引用真实不证明状态变化语义成立，仍须全文审查。

本轮是独立流程接入，不静默迁移默认平台v23。旧失败稿、旧视频、审核、未知结果和冻结源码全部保留。文本账本从511次、7,798,340 reported tokens承接，旧70/160未知及93,117预留保留；不重置旧额度、媒体失败记录或格式恢复额度。

官方允许同账号近30天内的指定可信模型原始视频及服务尾帧再作为输入；不支持跨账号、跨平台或二次剪辑产物的信任迁移。首帧模式与全模态参考模式互斥，不能简单在首帧请求里再塞多张角色图或参考视频。该许可不是人物或声线一致性的保证。

## 故障与返修

SDK运输自动重试关闭；每个阶段请求及回执不可变。完整结果、明确结束、非负用量均已知的内容合同失败，最多两次完整原生内容修订，旧失败与消耗保留。未知结果、截断、缺工具、未知用量或只得到审查unknown时，停止相应阶段，不盲重派。相同已完成阶段重启仅验账本并使用同一回执，不新增派发。

视频只一次提交新首段，不自动重试、不发布。助手不抽帧、听看、ASR或调用音画审核；只核对任务ID、文件完整保存及媒体技术元数据。后续仍按AGENTS.md逐段人工批准。
