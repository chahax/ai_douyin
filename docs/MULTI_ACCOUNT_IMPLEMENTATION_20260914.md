# 多账号与用量汇总实施记录

2026-09-14。本轮完成账号上下文、数据保护、用量筛选及发布/任务身份保护；未执行真实账号发布。

## 页面变化

- 侧栏统一账号范围：全部账号汇总、具体账号、历史未归属。作品、评论、回复、来源分析、剧本及制作页使用统一选择。汇总模式下，账号操作页要求先选具体账号。
- 账号页独立“添加抖音账号”：创建账号后再登录绑定。原绑定不会因新增而被替换。
- 官方中心保留普通链接，并增加专属环境入口：管理员点击后，使用所选账号环境、获取运行锁、验证身份，再打开官方管理页；关闭窗口释放环境。
- 用量页支持单账号与全部账号汇总；全部模式提供逐账号对比表。任务、成功数、生成秒数和 tokens 随范围切换，真实费用未接账单时明确显示未接入。
- 供应商余额保持公共账户口径，不能按抖音账号重复相加；单账号统计不会把公共预算当作该账号独立预算。
- 首页及制作项目筛选跟随账号范围。

## 后端变化

- 新增 artifact_account：只从显式账号字段及项目数据目录内的关联来源读取归属。来源互相矛盾时标记冲突，不根据当前页面账号猜测。
- 生产准备与方舟报告写入已解析账号字段。项目按账号及已有项目/稿次标识归组，合成只有在所有输入账号一致且有依据时继承归属。
- 生成台账按供应商与任务 ID 去重；同任务归属冲突时只计一次，归入待核对。不同任务 ID 的实际重试分别计数。
- save_video 阻止已存在记录跨账号改写，也不自动认领无归属历史记录。同标题多个待发布记录不再批量匹配；只有同账号唯一候选才按行 ID 更新。
- get_videos / count_videos 使用 None 表示全账号，空字符串仅表示未归属，避免空账号意外查询全量。
- 发布前核对请求和已知成片归属；写入账号 UUID、真实平台身份及验证时间快照。防重复提交键基于实际平台身份和视频摘要，同时兼容旧提交锁。
- 换绑保留原绑定快照到 account_binding_history；暂停/停用账号不能启动浏览器任务。
- 队列入队时冻结带 account_key 参数的任务账号、策略版本和平台身份；执行前发现变化则不自动重试。没有账号参数的通用非账号任务保持原行为。

## 验证

累计 37 个不同测试通过，包括既有账号、作品、页面、生产流程回归及新增双账号用例：

- 单账号/全账号切换，汇总秒数可对账。
- 同任务回执去重与冲突归属处理。
- 跨账号作品保存、空账号查询边界、同标题草稿保护。
- 发布请求即使填写当前账号，也不能覆盖成片的不同归属。
- 同一实际身份更换运营账号标识后，仍阻止重复提交；不同实际身份独立计数。
- 后台任务换绑后不继续执行旧快照。
- 已有余额权限、刷新失败保留快照、最新成片和旧生产脚本测试。

执行批次：multi_account_final_tmp（30 项）、multi_account_publish_checks_tmp（新增发布用例通过）、multi_account_runner_tmp（4 项）、multi_account_dedup_tmp（新增冲突去重用例及页面回归通过）。测试临时数据均位于 data/qa。
