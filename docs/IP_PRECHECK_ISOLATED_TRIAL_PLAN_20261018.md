# 品牌与 IP 引用预检隔离试验

日期：2026-10-18。用户要求“安装下来试试，记得隔离”。

## 范围

在 `tools/ip_precheck_lab_v1` 内创建独立虚拟环境、CPU 依赖和模型缓存，基础解释器只读复用已安装 Python 3.11.15，实际运行 GLiNER 多语模型与 spaCy EntityRuler。只读取本次 S1A 实际提示词，并运行带期望实体的中文对照样例；不读取 `.env`，不调用创作、审核或视频付费接口，不修改生产入口、原提示词、账本及冻结文件。PaddleOCR 是图片文字工具，本次无参考图，暂不安装。

## 隔离与来源

- 独立解释器/venv，不使用项目 `.venv` 的 site-packages，不改全局包。
- 下载、pip/uv、Hugging Face、Torch 缓存及临时目录均定向至试验根；生成 Git 忽略规则。
- 从 PyPI、PyTorch 官方 CPU 源及 Hugging Face 作者模型库取得依赖/模型，记录版本与模型 revision/hash；只加载 safetensors，不启用远程模型代码。
- 实际 Hugging Face 直连连接超时，下载传输改用 `https://hf-mirror.com`。GLiNER 固定作者官网可核对 revision `443d26d654e0324125a96bebd8e796c14ff2efe6`，权重 SHA256 `2100142f31627531497850659dcb3821c99d5e71c08a8e01a98e4b11ef32a199`，不把镜像自身声明当作独立真实性证明。
- 模型下载与本地推理分开。正式样例推理采用离线模式，禁止推理进程网络访问；项目正文不发送至外部推理服务。
- 记录受保护文件的前后 SHA256 和解释器/包来源，验证生产环境未变。
- 注意本轮 BASELINE 在独立依赖安装之后、模型推理之前捕获；不能用它声称已提供安装前后的全量主环境对照。安装定向由实际命令的独立 `--python` 路径、独立包位置、venv 配置和依赖冻结证明。该隔离是依赖/缓存隔离与 Python 推理网络门，不是操作系统沙箱。

## 实施与验收

1. 主 agent 创建隔离环境并安装；子 agent 编写独立样例/评估器，主 agent 审查。
2. 使用已许可的多语模型 `urchade/gliner_multi-v2.1`，词库只作演示，不宣称完整品牌/IP覆盖。
3. 测试真实原提示词，以及明确品牌、作品/角色、别名、普通虚构人名、普通物品和同名歧义；记录每条候选、原文位置、模型分数及词库来源。
4. 报告 GLiNER、规则词库各自的正确/漏检/误报，不将词库精确命中冒充模型识别效果，不把抽取结果称为侵权判定。
5. 保存可复跑命令、依赖冻结、原始结果和中文结论。样例用于可行性筛查，不能证明普遍生产质量或预测 Seedance 输出版权门。

## 停止边界

安装失败先保留日志并定位兼容性；不替换主环境、不静默换未知模型。试验没有授权提交新视频、媒体重试、发布或修改既有生产任务状态。

## 实际结果与交接

已安装并顺序完成三种本地配置的18条固定样例与真实 S1A 提示词试验，细节见[完整报告](../tools/ip_precheck_lab_v1/results/REPORT.md)。中文空白适配后，严格实体评分TP20/FP16/FN8（精确率55.6%、召回率71.4%）；词库TP22/FP0/FN3，仅代表演示样例覆盖。真实提示词无演示词库命中，但模型将内部段号S1-A识别为作品名，故不能作为独立版权放行门。

已修复本地缓存引用、缺protobuf、中文边界及纯空白词索引错位；两次加载失败、三配置结果、旧源码快照和独立最小复现均保留。最终入口默认使用spacy-zh-nonspace，仅实验目录生效。实际下载固定revision和官方权重SHA核对完成，61包依赖检查兼容，30个受保护文件与主项目包列表核对未变（安装后基线的证据边界保持）。没有新付费推理、视频提交或生产接入。
