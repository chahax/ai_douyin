# 剧本 Agent V2：容量、任务上下文、局部返修与复核

日期：2026-11-01。本文记录本次已实现内容；真实测试最终结论见文末追加结果。原历史入口和失败证据保持不变，未迁移网页默认生产、视频或账号发布流程。

## 实际实现

新入口 `scripts/run_script_agent_v2.py`，支持完整生成和当前稿审核恢复。模型仍为 MiniMax-M3.1-Flash xhigh 与 DeepSeek deepseek-flash high。

### 模型能力与任务预算

能力注册表保留服务商、模型、接口、上下文、最大输出、推荐预算、推理档位、官网来源和核验日期。每次任务冻结快照；不是将任务输出预算当作服务商最大容量。

本次 MiniMax 官网 OpenAPI 推荐128K输出，上限512K，1M上下文按保守1,000,000登记；DeepSeek 官方 `/models` 实际查询确认1,048,576上下文、393,216最大输出。MiniMax能力来自官网快照，DeepSeek额外实时核验；未声称两个厂商均自动实时刷新。

- MiniMax任务预算：131072，已知length可扩大一次至262144。
- DeepSeek high任务预算：65536，已知length可扩大一次至131072。
- 保持输入和节点不变，只提高失败节点的输出预算；保存每次原生请求、终态、用量与恢复来源。
- 无完整终态/用量的未知请求不自动重发；格式错误不冒充length扩容。
- 总等待时间随预算增加，SDK读流空闲超时仍90秒；持续有输出不会触发固定的900秒总截止。

容量使用 `cl100k_base` 代理分词估算，加35%或至少2048 tokens余量。明确标记 `exact=false`，不是MiniMax/DeepSeek精确分词器。估算接近上限时返回“需要精确计数或缩小范围”，不静默截取原文，也不把UTF-8字节数假装成准确token数。最终用量以服务端回执核对。

### 节点上下文

| 节点 | 输入 | 明确不继承 |
|---|---|---|
| 生成 | 完整目标章节、选定完整前情、制作要求 | 无关聊天、历史失败稿 |
| 独立整稿审 | 原文、当前稿、制作要求 | 旧审核结论及模型推理 |
| 意见核验 | 原文、当前稿、待核意见、与人物/原段相关的处理记录 | 无关问题记录 |
| 局部返修 | 当前稿、原文、已核实问题、多处补丁范围、相关记录 | 完整旧聊天 |
| 定向复核 | 修改前后稿、原问题、实际补丁、原文 | 无关返修历史 |

都是独立API请求，但按任务显式传递业务状态。当前前情选择由任务参数指定，不冒称已经自动检索全书所有必要材料。完整章正文与原段号均保留。

### 审核分级与问题记录

- blocking：人物、主体、因果错误，以及必要目标事件、互动、信息性对白遗漏，必须返修。
- production：已有剧情如何落实为布景、首帧、道具、声音等，在相关媒体生成前处理。
- style：可选表达优化，不触发自动重写。

定向复核返回的全部新观察必须登记并进入下一次意见核验；后续独立审核没再提到，不等于它已解决。只有绑定对应候选的检查结果可把问题置为resolved。问题记录绑定原文、候选和报告摘要校验值；未决不会被自动补成事实。

实际仍依赖模型语义判断，可能把剧情遗漏错误降级；因此当前输出状态为待主助手验收，模型不自动释放媒体任务。`ready_for_primary_review` 不等于整稿已验收。

### 多处补丁与循环

一个问题可以关联多处不连续文本，例如背景、正文和待核。程序要求每处引句唯一，范围不重叠；模型须一次返回全部edit键，允许空串删除。候选或意见版本变了即拒绝应用。未选区域由程序原样保留。

默认最多两轮返修；已知length每节点只扩大一次。24调用是本次完整样本的工程停止边界，非套餐额度。后续处理同一测试缺陷时继承原任务剩余额度，不重置上界。

定向复核失败且提供了当前有效修改范围时，意见进入下一轮核验/返修；缺范围则明确停止，不猜修改位置。相关问题核验完后，仍需独立整稿审核。
