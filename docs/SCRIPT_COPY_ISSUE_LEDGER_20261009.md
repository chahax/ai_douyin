## 后续文案与制作验收

1. **完整正文**：每句话能让人知道谁要什么、为什么不一致、对方怎样回应；不用流程暗语替代事实。相同事实第二次说出时，压力、立场或关系应有变化。
2. **冲突和情绪**：整片标明压力→选择→后果→释放。每次关键反应能指出刺激来源；不能用“克制、停顿、凝视”三个词覆盖全片，也不把情绪升级等同于争吵。
3. **导演规划**：逐镜写新增信息、观察对象、刺激与反应、切镜理由。道具操作只在改变信息、责任或关系时保留。先安排情绪重点，再安排服务切段。
4. **局部表演**：区分当前台词、当前非言语动作及反应窗口。台词前后留必要时间，普通对白自然稍快，关键质问可变速；无新增信息的等待不凑最低时长。
5. **确定性编译**：按源步骤编位置与持有变化。新16步骤不可套旧14步骤/table_middle合同；对白每句恰好出现一次，未来对白、工牌和离场不提前进入当前段。服务整数秒余量不等比例拉长整段讲话，相关新投影尚待实现。
6. **全文复审与人工审查**：MiniMax提交完整新稿或完整模块，DeepSeek审查全文；审查建议须核对是否来自用户目标，不能为凑句数、凑最低时长或强制同拍而返修。离线通过、接口成功、有效完整文本与人工创作通过分别记录。

上述是后续验收要求，不能写成已落实的新导演、表演或视频。当前339正文采用问题仍待用户答复；本次文档整理没有派发模型、媒体或发布请求。
