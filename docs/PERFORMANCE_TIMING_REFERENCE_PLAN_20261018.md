# 动作、对白与情绪排时参考：本轮范围

用户要求核对其他段，并希望形成“什么动作、什么情绪大概占多少时间”的通用规范。当前其他段仍为旧72秒编辑建议，只有S01另存7秒候选；本轮先逐段重排完整建议稿，再把参考规范交给后续新任务。

本规范是项目的创作排时起点，不是行业统一标准或已证实的成片规律。普通状态直接呈现；参考区间用于估算、发现空耗和过挤，不能要求每个动作演足下限，也不能仅按字数判内容通过。重要反应按具体刺激、变化和镜头可读性安排；所有视频仍由用户人工审核。

实施分工：

1. 主agent保存本方案与时长参考文档，审查完整修订稿、实际SDK预览、依赖和状态；不播放视频、抽帧、ASR或新增付费调用。
2. 子agent按相同参考对S02—结尾重排，普通动作与对白并行、必要反应保留明确作用，短收尾可并入相邻段，禁止只按比例缩秒。继承7秒S01及当前世界初态，完整稿另存为助手编辑候选，不冒充MiniMax/DeepSeek新验收。
3. 独立`performance_timing_reference/v1`保存可读的动作/反应/对白参考区间与排时方法，完整副本和SHA进入新任务brief。保留`content_end_pacing/v1`及旧v9/v10代码冻结，新入口只对新任务启用；已有任务走原入口恢复，不补写旧brief。
4. 排时按依赖关系计算：能并行的对白/动作/听者反应用同一时间窗，只有真实先后依赖才另计时间。最后有效内容完成即收段；服务整数档与硬范围仍按既有合同核对，编译器不自动改导演原秒数。
5. 离线验证新规范到五个真实文本请求材料、所有新候选时段累计/SDK时长/对白完整及空间道具交接；测试或文本核对不写成新稿语义生产通过或视频通过。

本轮不扩大已耗尽的十轮文本测试，不调用MiniMax/DeepSeek，不生成新图/视频，不修改旧媒体、原生账本和审核记录。
