# 能力优先流程：自主接入与生产测试计划

用户本轮要求：“这些审核你可以直接进行，人物你可以主动接取，这些都是正常的重构修复流程的你可以自动运行的”。此前已要求文档先行、子agent修改、主agent审查。本计划先于本轮子agent开发保存，承接[修改方向](CREATIVE_CAPABILITY_FIRST_IMPLEMENTATION_PLAN_20261012.md)与[离线审查交接](CREATIVE_CAPABILITY_FIRST_REVIEW_20261012.md)。

## 执行方向与授权解释

代码审查、文本全文复审、现有素材发现/取回/身份核对和正常重构接线由助手自动执行，不再逐项请求批准。保持MiniMax-M3创作、DeepSeek少量必要全文审查；后续文本不设总token预算。视频内容仍由用户人工审核，不抽帧、听看、ASR或调用音画审核模型，不发布。

本次自主续行采用新独立生产适配与新冻结，不重开旧probe_v4、不改其4/4或旧授权、回执、消耗。将当前明确“自动运行”作为本轮文本生产测试的授权来源，新增候选按有界运行登记：最多三份完整原生整片导演（累计上限由4增加到7，历史四份完整承接），局部已知完整内容失败最多两轮原生整稿返修，全文复审仍按原失败类型路由。结果未知、用量未知、截断、未决claim不得重复派发；SDK自动重试关闭。

新增额度是本轮明确自主运行授权下的有限测试范围，不是改目录清零或模型余额重置。主agent先完成入口、实际SDK出站参数/素材证明和离线负例审查，才执行新文本测试。新增图像、视频重试、批量续段和发布不由本计划推断授权。

## 素材接入边界

既有明确采用的人物/场景原文件可主动取回并核对原服务任务、哈希、当前身份和适用范围。旧视频的原服务尾帧是原始素材，不允许从旧视频重新抽帧代替；缺人设匹配证据时如实标pending。用户委托助手选取素材可以记为本轮委托选择，不能伪写为历史逐图用户批准或视频通过。

素材索引不输出签名URL、凭据或完整服务秘钥。同账号原GET、精确模型/30天资格、下载URL期限与人工视频质量分开；当前没有真实音频绑定的声线仍unbound。已有图进入导演实际image_url请求后，要保存实际出站覆盖证明。暂不凭名字将Seedream未知来源图片登记为受信原生产物。
