# 图片小样与分流返修验收

## 范围

用户批准两套本地图片模型下载、试验，以及先开发并进行黑盒测试。模型与缓存均在 D 盘；原 H3 完整稿批次继续人工暂停。不涉及账号、发布、外部模型、后台重启或生产迁移。

## 已实现

- `src/content_factory/visual_repair_flow_v1.py`：审核绑定项目摘要；按资产、构图/调度、视频动作/形变、声音、字幕分流；共享资产依赖展开；保留原产物，取消有问题版本的交付资格。
- `scripts/visual_repair_flow_v1.py`：独立文件入口，输出只创建不覆盖。仅登记返修，不暗中调用生成模型或解除暂停。
- 图片试验入口 `data/image_model_trials/20261105_klein_qwen/run_serial_trial.py`：完整文件大小和官方 SHA 校验后，串行执行已有独立 ComfyUI 图。Klein 先生成成人、儿童、环境三张候选，再用同源图片分别测侧面、双人、环境反向机位；随后 Qwen 做同输入三项编辑。
- 图片调用沿用 `run_image_case.py` 的单次 claim、原 prompt ID 收存和未知不重派机制，结果保存实际生成图、原生 history 与资源采样。试验图不自动升格为已批准资产。

## 代码和控制黑盒

最终 XML：`data/qa/visual_repair_flow_v1_20261105.xml`，36 项通过，包含原资产编译门回归、多问题前置顺序以及输入重排不能提前执行视频的保护。此前 30/34/35 项是同一组中间态，不累计。

五条独立进程 CLI 黑盒路径：共享人物资产、视频动作、画外声音、口型声音、后期字幕。核对真实输出文件、影响范围、暂停保留、过期计划拒绝以及旧结果不覆盖。黑盒输入为隔离夹具，不是原生成片的语义验收。

首次 pytest 自动加载第三方插件停滞，已中止该测试会话；关闭第三方插件自动加载后完成上述检查，项目 conftest 的生产数据库保护保持启用。无修改生产依赖。

## 仍须验收

以试验根 `PILOT_STATE.json` 和 `cases/*/RESULT.json` 为准。两模型已完成原生图片测试；旧 `PILOT_ERROR.json` 保留的是主动中断的 40 步试验，不是当前仍运行或未知结果。下载完成不等于语义通过，原生图片保存不等于人物或空间一致性合格。视频多镜头新链尚未验收，管理界面尚未接入此控制入口，返修控制 CLI 尚不执行生产生成或自动语义审核。不得据 36 项程序测试声称整链无人生产通过。

流程图见 `NOVEL_VISUAL_PIPELINE_V2_FLOW_20261105.md`。

## Klein 原生与真实失败黑盒（本轮更新）

三个模型文件均完整官方 SHA 通过；实际为 BF16 主模型、FP4 文本编码器，非全 BF16。三张基础图、三张同输入编辑图及一次独立换机位返修图均已原生保存，768×1024，原生执行 3.783—16.782 秒，采样显存最高 13,506 MiB（5 秒采样会漏掉短任务峰值，不视为精确峰值）。实际原 ID 与图片 SHA 见试验根 `CASE_METRICS.json`、`cases/*/RESULT.json`。

助手可视审查：单人完整、双人同框保持了明显身份/服装特征；侧面仍有三分之四角度，不算严格正侧视资产。首次房间提示同时要求反向且朝原门看，存在提示歧义，不能独据它归咎模型。第二次明确相机在门口向另一端拍摄，仍保留原视角并多出一盏灯。环境多视图不通过，不据此冻结正式环境资产；基础人物图也是通用试验候选，未替代小说原角色。

真实失败黑盒：`data/image_model_trials/20261105_klein_qwen/real_failure_blackbox_v2` 使用明确机位请求的实际失败图和 SHA，助手可视审核记录通过公开 CLI 生成并应用分流计划。`ASSERTIONS.json` 核实仅登记 compose_first_frame、资产卡不变、原图不删不改、失败图取消交付资格、暂停保持。首轮歧义提示的旧记录保留在无 v2 后缀目录，不作为最终语义失败依据。审核判断来自助手，不冒称已实现无人语义审核；返修图片由本轮授权的独立小样入口执行，不是该控制 CLI 暗中派发。

## Qwen 原生与速度试验（最终）

主模型 INT8 ConvRot 20.50GB、专用 FP8 编码器 9.38GB、VAE 和官方 Lightning 4 步 LoRA 849.6MB 均完整 SHA 通过，已导入原 Comfy 模型目录，无服务重启和依赖升级。原 40 步约 1MP 案例因约 67 秒/步而由助手明确中断，已取得 execution_interrupted 原生终态、保留原 ID 与记录；没有输出，不据此判断 40 步质量。

独立速度变体：512×688、4 步、CFG1、Euler/simple、LoRA 强度1，四张均保存，195.900—206.176 秒/张；最高采样显存 15,263 MiB。相同参考原文件与文字提示输入，但分辨率/步数/量化不同，不作等质量排名。

人物能保持大致服装与人数，但严格侧面和人物细节未达到冻结标准；双人图孩子外观有变化。初版环境近似原视角；明确机位版把床窗左右调整，但门仍在后墙，属于镜像式重排而非从门口向内拍。环境反向多视图仍不通过。

本机建议：Klein 可作为快速人物候选与少量人物合成入口，Qwen 暂作慢速编辑试验。环境先固定布局与机位约束，再验证多视图；当前不能因两模型都能出图就恢复旧完整批次。

最终共11张保存（Klein7、Qwen4）、1次主动中断无图片；8190队列为空，原H3暂停文件保留。试验总状态与实际参数分别见 `PILOT_STATE.json`、`CASE_METRICS.json`、`SHARED_INPUTS.json`。
