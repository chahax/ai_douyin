## 已确认并修复的缺陷

| 范围 | 结果 |
| --- | --- |
| 原人工窗口 | 原owner、代次、账号绑定及心跳共同证明窗口归属；过期探测不再显示为“当前无验证”；旧核验不等于现在已恢复 |
| 系统重启后的旧任务 | 新增原ID/请求SHA/开机证据绑定的显式结清入口，原记录入审计；不清业务锁、不关异常、不核验身份、不重派或恢复账号 |
| 异常呈现 | 同账号一组窗口/继续操作；长历史诊断折叠；未恢复的后台故障阻止账号继续；账号/调度页避免全局和本地重复按钮 |
| 状态证据 | 缺数据、读取失败、非法/未来时间、过期心跳显示未知；不把服务健康、候选数量或running当作已播放 |
| 规则、违禁词、用户管理 | 空白/坏正则/缺模型拦截；检查保存真实返回值；反馈跨重绘保留；删除需要对象确认；失败不报成功 |
| 违禁词存储 | 只在首次新建库时播种默认词，用户删空后不因读取而复活 |
| 记忆 | 当前用户过滤覆盖提醒和主题查询；查看情绪不创建新会话 |
| 知识库 | 普通查看不导入模型；复制文件与写入索引分开；部分/未知写入不报全部成功；相同片段稳定ID复用 |
| 文本模型依赖 | 项目要求sentence-transformers >=5.7,<6；5.7.0官方wheel已隔离验证并按本次授权部署。仅更新这个包，Torch/FFmpeg未更新 |
| 检索降级 | 远程模型fallback关闭时，检索失败不会偷偷开启远程加载；本地文本嵌入使用CPU |
| 调度 | 查看页面不启动后台；停止按钮明确只停止定时调度，不误称Worker/在途任务也停止；启动失败按真实结果反馈 |
| 启动清理 | 原未就绪worker家族先回收，管道关闭有界；真实隔离启动45.05秒返回超时且cleanup_verified=true，不再无限挂住 |
| 页面错误 | 失败区域清空半截表单，给出安全未知状态及重新读取入口，不在页面展示原始异常栈 |
| 配置与制作标签 | Ark/BytePlus/Dreamina分别显示；历史生成记录、技术收存和人工内容审核不混为完成 |
| AI助手计划 | 修改前真实控件复现确认按钮重绘失效；现在从原会话恢复计划、按钮绑定原会话/计划SHA、唯一受理回执防重复，取消不调用模型；结果未知不重发 |
| 会话管理 | 修改前复现归档恢复NameError；修复事务与用户归属，读取不新建会话，标题/删除有真实反馈；删除确认绑定原版本，未结清计划保留 |
| AI助手权限 | 查看者可以读自己的会话，不能发起模型请求或确认执行；服务端也重新判断权限，不仅依赖按钮禁用 |
| 技能中心 | 编辑者仅本人调用记录，系统诊断仅管理员；筛选/详情只读，目录和存储失败不暴露原异常；该页没有安装或执行技能按钮 |
| 历史记录边界 | 拒绝项目授权目录外路径，只读浏览限定在data/creative_workflows；不启动旧runner |
| 模型用量 | 未记录费用不等于免费；已记录费用、缓存命中、平均延迟分别按已记录字段统计 |

知识库依赖依据：[官方5.7.0修复说明](https://github.com/huggingface/sentence-transformers/releases/tag/v5.7.0)，对应可选TorchCodec失败时文本导入也崩溃的问题。未修改安装包源码或用假模块绕过依赖。
