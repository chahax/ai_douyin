# 普通发布后评论的同源核验透传

本轮只接普通`browser_control_runtime._publish`到已有授权评论函数，不发起上传、发布、评论或服务操作。共享公开页观察分支由另一个子agent实现；它要求冻结title/hashtags与实际完整核验中的expected_title/expected_hashtags一致，不能用摘要verified或唯一article数量冒充实际核验。

保留`journal_evidence`原摘要。仅在确有授权评论时，从该摘要的原journal path/SHA读取同一次prepared和最后一次post_publish_checked完整evidence，确认journal仍为本adapter当前journal，prepared的标题/规范化标签/视频路径和SHA与冻结PublishRequest及payload完全一致，最后核验verified为真、准确ID与result一致、expected_title/expected_hashtags与请求一致，才原样透传。缺项、解析失败或错同源均停止评论并记comment_pending，已有提交锁和原发布结果保持，不能重传。没有评论授权的原发布行为不变。

任何授权评论结果未达到sent_visible/matching_comment_already_visible，都保留comment_pending并让管控状态为outcome_unknown，避免把已发布但评论未完成写成全部成功。不增加自动评论重试，不改原额度、core、浏览器worker或历史账本。

修改前源码副本保存在`data/development_checkpoints/publication_comment_evidence_bridge_20261019/browser_control_runtime.before.py`；精确模拟测试覆盖完整同源透传、错误ID/标题/标签拒绝、未提交评论不伪报完成以及无评论默认路径。主agent核源、审查后才决定部署。
