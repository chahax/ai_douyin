## 标准的范围

以这条片子的表达机制作为当前创作与导演的审美依据。片中剧情、人物数量、转场数量、时长、悲剧结局不是本片必须满足的模板。样片制作模型、提示词、选片和后期投入未知，不能承诺只改提示词就达到相同成片质量。

可复用流程需要每次先确定主题、人物关系、观众感受、画风、阻力和结尾，再说明哪些参考机制适合该故事。不适用的技巧可以不采用并说明原因；不要求每镜同时体现全部技巧。

## 四项表达要求

| 要求 | 参考依据 | 本片可检查的问题 | 责任阶段 |
| --- | --- | --- | --- |
| 画面提供信息 | 20–31秒，前景表演关心与后景自在吃东西形成反差 | 除了听到对白，观众能从人物行动、构图或道具关系知道什么？是否重复已有信息？ | 故事提供事实；导演选择可见证据 |
| 动作改变关系 | 转账、收款反应及消费展现付出与利用的因果 | 文件夹放到她桌上、递回、他开始修改，分别改变了什么？收拾和按键是否挤占这些变化？ | 故事明确因果；导演确定重点 |
| 刺激引起可见反应 | 48–50秒收款后兴奋；93–104秒愤怒到接听后的微笑 | 看谁、因什么改变、改变前后有什么可比较的差别？对白期间及之后是否有承载它的表演窗口？ | 导演定义变化；局部表演安排窗口 |
| 结尾兑现主题 | 老人的愤怒没有消除对关心的渴望；来电者身份未明确 | 工作由林屿接回后，方澄的离开怎样让观众感到她拿回自己的时间？结尾是否改变或加深观众理解？ | 故事选择结果；导演组织收束 |

这四项是有来源、有理由的创作判断，不是表情数、反转数、固定秒数或机器评分。对白也是有效叙事手段，不能把“去掉全部对白仍看懂”设为所有故事的硬门槛。结尾可以有余味，也可以明确释放，不强制惊奇反转。

## 最小流程调整

1. 创作简报增加一份短的“参考机制映射表”：参考时间与可见事实、可迁移机制、当前故事要表达什么、采用范围或不采用的理由。完整原简报和R01继续作为源材料，不用这张表替换它们。
2. 完整故事先验收压力、选择、后果、释放与创作边界。只有正文缺少事实或关系变化才回编剧；MiniMax提交完整新稿，DeepSeek复审当前全文，不由助手拼接内容。
3. 整片导演复用已有new_information、observation_object、stimulus、composition、cut_reason和performance_requirements。把映射表落实到这些字段及确切正文来源，说明观察到的前后变化。先审阅全片导演安排，再进入局部排时。
4. 局部表演接收已确定的摄影和反应目标、当前拍正文及编译器给出的起态，只安排实际可见表演、对白前中后的窗口和必要动作。不重新决定主题，不平分停顿，不补剧情。
5. 确定性编译检查源覆盖、对白顺序、道具持有、位置朝向、动作前提、窗口承载及生成段边界。关键刺激和反应不拆到不同请求；接口限制冲突时回导演调整，不悄悄压缩表演或自动换场。
6. 视频提示词从已确认的导演与排时投影，使用当前场景、表演和明确普通话。参考分析及内部ID保留在创作/审计层；不把长篇影评、全片元数据或未来事件直接塞入视频提示词。
7. 视频成功并完整保存后为awaiting_human_review。用户看实际结果，比较信息、反应、情绪和声音；助手不主动抽帧、听看、ASR或调用音画审核模型。用户批准服务原始尾帧后续段，图片与分镜沿用当前人工确认方式。

## 故障与质量反馈分流

| 现象 | 修复责任与范围 |
| --- | --- |
| 正文没有有效压力、选择或后果 | 完整编剧返修并全文复审；受正文变化影响的导演、表演、编译和交接重新绑定 |
| 正文成立，但观察对象不清、镜头重复或切得太早 | 整片导演返修；核对实际消费字段，受影响的局部表演与下游重建 |
| 镜头目的明确，但动作或反应无法在窗口内完成 | 局部表演返修及确定性编译，不自行改台词或剧情 |
| 缺工具、截断、类型错误或结果未知 | 保留原回执并进入对应接口/合同分支；未知请求先对账，不自动重派 |
| 提示词忠实投影，但生成视频演错、换场或语言不对 | 用户反馈绑定当前段，核对实际请求与能力边界，修复对应责任层后再决定重生成 |

文本审查无问题、离线编译通过、服务成功与用户创作质量认可分别记录。当前方案没有证明达到参考片的成片水平。
