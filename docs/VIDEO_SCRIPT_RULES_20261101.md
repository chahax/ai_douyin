# 当前小说视频剧本规则

更新：2026-11-01。用户要求补全规范并重跑前几章。本版用于显式测试配置，网页默认流程不迁移；真实效果以新测试记录为准。

## 目标和结构

把小说已有剧情写成能够生产视频的剧本，保留人物关系、事件主体、对白含义、因果和重要结果。不是自由续写；不要求逐字复述小说，不固定总秒数。

每章结构：必要背景 → 连续场景正文 → 已落实的制作决定。

必要背景简述本段需要的世界背景、人物关系与整体画风，不把前文剧情全部重新演出。每场标明时间、地点、在场人物和入场状态；对白、动作、神情、对方反应在同一段里交织。

## 画面与节奏

| 要求 | 实际执行方式 |
|---|---|
| 环境可辨认 | 首次出现或转场时，用短环境交代或人物与环境同框建立空间，迅速看懂场所和生活状态。 |
| 有生活感 | 少量家具、物件、材质与光影服务场景；按原文呈现简陋、陈旧、温馨等特点，不能一律套成温馨豪宅。 |
| 人物近景、特写 | 关键情绪、态度转折、重要对白适时给近景/特写；必要时写手部动作和对方反应。不要求每句话切镜头。 |
| 人物有行为 | 入场、犹豫、转身等与台词同步推进，不僵站对话，也不凭空添加事件或动机来制造动态。 |
| 镜头连贯 | 用动作、视线、情绪承接，保持空间和道具连续，避免突然放大、跳跃位移、人物凭空出现。 |
| 信息尽快进入 | 开场尽快说明谁、在哪、发生什么；环境展示不拖长无信息空镜，必要情绪仍可停顿。 |
| 声画清楚 | 可见动作无需重复旁白。必要不可见信息用旁白或自然心声；第三人称旁白可以保留，角色心声不混淆自称和他人。 |

这是剧本设计标准，不是本阶段强制生成逐镜头时间码。普通光线、景别、合理微动作允许设计；它们不是小说新增事实。没有写出“特写”两个字，但已有明确表情动作可以拍摄，不单独作为失败理由。

## 原文和前情

- 原文优先于模型分析；未署名不能凭邻近姓名猜人，也不能把单人未知声音自动改为全员齐说。
- 计划、猜测、回忆、原书未来与现在分开；前情只帮助理解，不自动重演。
- 人物进出、持物、关键行动与场景位置保持连续。
- 前情按最近三章为优先回看范围：紧邻上章结尾与本章开头优先，近三章内分析次之；更早材料只在当前人物身份、关系、未完事项或实际冲突需要时使用。当前章完整正文始终保留。分析量增加不代表要把旧事全部演出。
- 模型分析不是小说事实；核对具体人物发言或状态时直接读相应原段。旧分析与原文冲突时，以原文为准，不把错误记忆继续传播。正文先修而资料未更新时，不能宣称整条资料链已经正确。

## 跨章、人物与场景一致性

- 开头承接上章最后的发言者、动作、位置与情绪；必要时用一两句已有信息帮助理解，避免整段前情重复。
- 同一人物的外貌、服装、伤势、手持物在同一连续场景保持一致；原文明确变化时跟随变化。原文没写的普通造型可选定为制作设计，不能把它变成新身份或新经历。
- 同一地点保持基础空间关系和主要家具位置，不因换镜头重新发明房间；离开、路上、抵达各阶段分清。合理过渡可省略，不必给每次走路单独一场。
- 区分“当前画面”“人物回忆”“猜测/计划”“原书未来”。观众需知道正在看哪一层，不能把未来的伤势、道具或事件提前出现。
- 对白保留说话目的和含义；原文未明确署名时可用不指定口型的单一画外声音，不强行猜名字或改为全员合说。心声与实际说出口的台词分开。

## 连载与分段

- 小说已有必要事件、反应和信息要完整呈现；可以合并同义叙述及无信息路程，不机械逐段配旁白，也不把尚需演出的事件塞进背景后跳过。
- 先写完整连续剧情，再按动作结束、对话落点或场景转换拆成视频段；章节边界不等于强制切镜，不能为了固定15秒截断一句话或动作。
- 每段只需带足够衔接信息：起止人物状态、地点和未结束动作。接段不重复上一段整句，不凭空换衣、换房间、换人。
- 结尾可停在原文已有的悬念或阶段结果，不新增反转和冲突做钩子；无需每章强行反转。

## 事实与制作设计

- 可以补合理景别、光线、微表情及不改剧情的表演动作。例如迟疑可以由视线、停笔表现，不必另编争执。
- 不把没写明等同于不能拍：普通家具、布景无需逐件找原文引用；但不能借布景增加“豪宅主人”“夫妻关系”“手里已有关键钥匙”等会改变理解的设定。
- 必要背景和制作说明应简洁，少用否定清单。交付剧本直接描述要出现的内容，不反复写“本段只生成……不生成……”。
- 优先级：人物与剧情含义清楚 → 声画和空间可理解 → 情绪节奏与画面表现 → 措辞精细度。后两项的轻微不足只记备注，不压过前两项。

## 小问题可跳过

验收以人物关系、场景、对白含义与主要剧情正确，且观众能理解、制作能执行为准，不追求零瑕疵。

**可记录后保留：** 普通措辞不够顺、轻微动作衔接、表情不够细、缺少某个景别词、床品挑选动作不具体、环境细节不够丰富、冗余说明。前提是不改变人物、事件、关键声音归属、实际位置或结果，也不造成制作无法理解。

**仍须处理：** 人物身份关系错、重要台词换人、关键剧情漏掉、无据新增事件、因果结果改变、人物或重要道具凭空出现、转场后位置仍错误。问题短小不等于影响小。

规范要求按实际影响判断：轻微表达/动作衔接可记录后保留，说明不影响剧情和制作的原因，不因旧标签叫“制作问题”就反复返修。人物关系、必要剧情和因果等核心问题仍须处理。

关键问题只做有据局部修复，不为小问题重写整章或无限循环。JSON不完整、修改地址不唯一等属于程序运行问题，不能伪装成风格小问题忽略。
