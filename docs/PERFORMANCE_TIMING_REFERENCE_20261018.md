# 动作、对白和情绪反应的排时参考 v1

这是一套用于本项目新短剧的初始创作参考，并非行业统一标准，也不是根据文字即可预测成片的保证。数值表示一次自然、可读的表现通常可以先怎样估时，需结合说话方式、人物处境、道具难度、距离和景别调整；不能要求动作必须演足下限，也不能自动把超出区间的表演判失败。

## 先判断是否需要单独占时间

普通状态直接呈现。平静、绷着嘴角、防备、已经疑惑等可以在开镜或切到人物时已经成立，额外的“从中性脸变到该状态”用时为0。

普通动作随对白完成。看对方、点头、取票、推票、收票、站起可以在合适的对白中进行；反应发生在刺激已经到达之后。听到“票买好了”并看见票时可以直接意外，不能在关键信息尚未出现时提前演出已经听懂。

关键反应按表达目的保留。防备变为理解、愧疚被说破、听懂“回家不是退回来”后的释然，必须让观众看清变化，但不要求依次演完吸气、皱眉、吞咽、起笑、流泪等整套过程。

## 动作参考

| 内容 | 初始参考 | 排时方式 |
| --- | --- | --- |
| 普通神情已经成立 | 额外0秒 | 直接展示，时间由当前对白或互动承担 |
| 一次目光转移、点头 | 0.2—0.6秒 | 通常与对白、递物并行，不另排尾窗 |
| 桌面一次拿、放、短距离推物 | 0.5—1.2秒 | 一个动作的参考，不把完整多步交接都算成这一个动作 |
| 从内袋取物、把简单纸票收入袋 | 0.8—1.8秒 | 根据袋口、折叠、手是否占用等调整 |
| 两人简单递交物件 | 1—2秒 | 交接、抓握、松手有先后，可与对白并行 |
| 正常起身 | 1—2秒 | 结合椅子与人物情况调整，不能同时已经在门口 |
| 约1—2米短距离走位 | 1—3秒 | 只是粗参，拖箱、绕桌、门的位置都影响时间；允许清楚切镜省略路程 |

这些动作的“可见时间”不等于额外加在对白之后的时间。手已握箱杆时要用哪只手拿票、收通知，必须写清。掏票→放桌→推票这类有物理依赖的动作保持先后；“并行”不是让同一只手同时完成互斥操作。

## 情绪与反应参考

| 内容 | 初始参考 | 保留条件 |
| --- | --- | --- |
| 轻微疑问、意外初显 | 0.3—0.8秒 | 往往在对方末句或递物中已经可见，不再追加同义反应 |
| 听懂关键信息、确认判断 | 0.8—1.5秒 | 信息确实改变理解，可放在对方说话时的听者近景 |
| 防备松开、愧疚显露、释然等关键变化 | 1—2.5秒 | 说明谁受到什么刺激、由何状态变成何状态，并让脸可读 |
| 压住泪意、重要选择、重大关系转折 | 1.5—3秒 | 只在确有分量的节点选择，不能每句都套用；不要求完整哭出来 |
| 内容结束后的普通凝视、保持表情 | 额外0秒 | 话、动作、必要反应完成就切走或结束 |

关键反应可能贯穿一整句对白，表中范围是安排可读窗口的起点；它不必全部发生在对白结束后。是否需要更长，要指出具体作用。字幕、远景或“震惊”等情绪标签不能代替看得清的表演。

## 对白参考

普通交流可先按每秒约3—4个实际发音汉字估算；有分量的情绪句可先按约2.5—3.5个估算。读数字、日期、缩写或专有名词时按实际读法计算，标点不算发音，但真实的换气、停连和接话需要空间。

这是排查“明显挤不下”和“短句被拖长”的辅助参考，不是按字数自动审核质量。最终仍需自然试读与同稿内容审核，不能让演员加快念词或拖长字音凑段长。

## 怎样合计

先把互动拆为有因果的顺序组。一个组里，能同时发生的对白、动作、听者反应放在同一时间窗；只把确实必须在它之后发生的内容再接上。

例如，女儿说话4秒、父亲同时取票1.2秒，这一组约用4秒；父亲回应并推票2.5秒，女儿在看见票和听到信息后同步意外，这一组约用2.5秒。两组连续约6.5秒，可由创作者安排为7秒服务段。不能再把取票1.2秒、普通意外0.8秒、回看0.5秒全部加到尾部。若必须再保留关键判断，就在创作阶段明确该内容及时间。

内部可以保存小数估时，发送Seedance Mini时用动作顺序、并行关系和明确收束表达；不向视频模型强压小数时间点。服务档位仍为4—15秒整数，整数秒由创作者确定并审核，SDK编译器不私自改时长。不足4秒的简单告别优先并入前段，超15秒的完整互动需删合或重新分段，不能用无信息等待或赶语速迁就接口。

## 编剧、导演和审核怎么使用

每段内部记录：这段新增什么信息、对白和必要动作、哪些同时发生、哪些必须先后、关键反应的刺激和作用、最后有效内容、结束时人物及道具状态。这里是工作检查表，不要求MiniMax另交固定JSON或按标题格式过关。

MiniMax据此完整创作；DeepSeek对照来源、同一稿与全部真实请求，检查时间是否空耗或过挤。审核只给具体问题，不能替创作者悄悄删台词、压秒数求通过。新任务的参考规范及SHA随brief进入各阶段，旧任务不追补、不改变硬范围、预算、回执或既有失败。

实际生成是否自然、反应是否清楚、切点是否舒服，继续由用户人工审片。本规范不授权新的模型、图像、视频、音频或发布调用。
