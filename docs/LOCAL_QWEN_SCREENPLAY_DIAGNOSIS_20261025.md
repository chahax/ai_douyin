# 本机 Qwen 剧本实验与失败原因（2026-10-25）

本次按用户要求实际运行本机模型、下载较新的开源模型，并区分提示词、上下文、流程与模型能力。未修改模型原生正文，未切换生产提供商，未调用云端文本或媒体模型，未重启账号服务。此前生产稿仍未验收通过。

## 实验方法

原输入来自 `data/novel_platform_trials/20261025_six_children_flow_v4/CALL_001.json`；对应同一本小说、同一原始请求系统提示、90秒目标。没有使用助手手改稿作为模型输入或交付。

- baseline：原生产首稿请求原样发送。
- anchored：只追加本集边界“叶东被诬陷偷二十元、继父到校查清并维护他”，其余保留。
- staged：先让模型产生事件节点、对白、串行动作和末态，再由程序按对白量分配时间；计划不合格便停止，不能当作完整稿成功。
- focused：保留既有69章分析档案，仅向编剧发送第6—7章原文及关系、钱款归属等支持事实，再给本集边界。
- focused_thinking：与focused相同资料，开启Qwen3.5思考；输出上限由6144增加到8192，因此不是仅一个参数的严格消融。
- atomic_probe：8个独立逻辑例，分别检查年龄排行、钱物连续、说话对象和数字时长；标准答案不发给模型。

固定seed42、temperature0.5、context32768。每种配置仅1个样本，两个模型其余默认采样参数不同，冷/热加载时间不同；不能据此做模型总体排名。所有成功响应终态为stop。程序不输出内部思考内容；只评估最终正文。原请求、原生响应、输出、来源绑定及运行时间分别保存。

## 原因定位

1. **本集边界在流程传递中丢了。** 当前v4为避免失败稿锚定，在组装首稿上下文时去掉 `selection` 和 `global_analysis`，但没有单独保留经过来源核对的事件起止边界。实际原请求只有3—7章原文和18条跨事件事实，模型要自行选事件。这是流程传参问题，不只是文案写得不够强。
2. **旧选段摘要本身有错，不能直接加回。** 历史选择把学校事件写成4—6章，实际关键取钱画面在第7章；旧摘要钱款动作也有误。事实表f13已纠正，但宽泛原文仍带入不必要支线。应把69章分析用于选题，再冻结可核验的本集简报，不能把全部分析都要求在90秒里呈现。
3. **一个调用承担太多互相牵制的任务。** 同时要求选段、忠实改编、对白、表演、摄影、道具连续和精确秒数；失败后全文重写又会带来新错误。此次分步计划试验同样失败，所以不能声称“拆成多个agent已经解决”。要先让小步骤的输出合同可验证，再逐步写完整稿。
4. **程序检查存在盲点。** 思考版全部使用“角色：（动作）台词”，没有引号；原生产时长解析只提取引号内容，竟返回0语音单位。这里的“0个超时”是漏统计，不是时间可行。实验测量已追加 `speech_measurement_usable=false` 与可疑行证据；原生产解析器尚未迁移此检查，不能说生产漏洞已修。另两份数字通过的9B稿也存在明确人物错误，证明数字和语义必须分开验收。
5. **模型能力也有影响。** 旧7B在简短年龄题都出错；新9B小题更好，但长稿仍丢人物与状态。聚焦资料和思考改善了部分表现，未消除错误。没有证据把全部责任归到某一个模型或某一句提示词，更没有证据指向CUDA故障。
6. **审核次数不等于独立可靠性。** 之前真实云端记录已出现两轮审核漏判、引用协议返修消耗调用等问题。再加同类全文审核不能替代对白统计覆盖率、可核验的角色/道具状态和来源证据。

## 建议的生产改造边界

保持现有账号管控、调度、原任务账本；只改内容生产模块。建议的数据流：

`全可读章节分析 → 有来源证据的本集简报 → 场景节点及人物/道具起止状态 → 程序分配时长 → 自然剧本 → 格式覆盖检查+独立事实审查 → 验收/返修`

- 本集简报必须带人物名单、在场集合、起因、钱物归属、要呈现的结果和原文证据ID。取舍允许改编；身份矛盾、同一物品状态跳变等不能靠审核投票放行。
- 计划只生成有限节点及对白，不让模型猜每段固定15秒。程序按对白、交接停顿、串行动作预算；模型负责自然表达与表演。
- 小型计划/审核可用本地JSON Schema约束形状，避免本次“要3—8段却只给2段”的格式失约；Schema本身不保证剧情真实。参考[Ollama结构化输出](https://docs.ollama.com/capabilities/structured-outputs)。
- 自然正文要核对对白是否完整被统计；不能识别时标记不可测，不能当作零对白。镜头、人物状态及事实则另做内容审查。
- 原始响应、失败、来源及预算全部保持。先用本次样本回归，再用未参与调试的其他故事验证；不能把同一故事调通称作通用生产完成。

本次只交付实验工具、测试和诊断证据，未将上述新结构或Qwen接成生产默认，未手改当前剧本。暂不推荐继续盲目下载更大的模型：本机9B已能运行，当前更明确的瓶颈是任务边界、可验证中间产物和整稿事实保持。
