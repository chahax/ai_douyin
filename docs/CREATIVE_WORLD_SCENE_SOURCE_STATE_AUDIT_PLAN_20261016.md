## 本轮最小实现与真实验证

新增独立的规划状态与动作作用审查合同，而不继续叠加正文提示。输入是完整原生规划、原始开场、brief/已确认要求、来源和R01；审查不预填上述已知答案。输出须绑定规划SHA，逐拍检查资源/道具状态、位置与在场、动作的新增叙事作用和情绪因果，明确区分意图与已经发生。明确失败给精确源路径、原文短引和跨拍关系；unknown如实保留，不冒充失败或通过。

审查只判断文本，严禁查看/听取视频。严格程序验收原生报告的类型、全拍覆盖、引用可逐字读回、主体与拍序、是否有互相矛盾的判断；程序不代替语义判断。离线正负控至少覆盖显式资源矛盾、静默表演无需无关操作、缺拍与假引用。实际请求不含人工写好的错误结论，避免验证变成照答案输出。

本轮独立授权范围为最多1次DeepSeek完整规划诊断，继承662全部费用/未知/冻结，保留八份失败正文和导演7/7，不新增正文、图片、视频或发布。原始结果/用量未知、截断或缺工具停止，不重派。调用只是新增必要文本审查，依据用户自主文本修复和少量必要DeepSeek审查授权，不再逐次申请。
