# 人物资产视图规范

现有双人同框与单张侧面只能作为模型小样，不能替代人物多视图。此规范用于后续人物资产候选；没有通过身份和角度检查之前，不能作为正式视频参考。

## 每个人单独一组

| 视图 | 检查重点 |
|---|---|
| 正面全身 | 头、双手和双脚完整，固定身材比例、衣服和鞋 |
| 朝画面左45°全身 | 身体和头部同向转动，仍为同一人 |
| 朝画面右45°全身 | 独立生成，保留发型和服装特征 |
| 朝画面左90°全身 | 鼻尖朝左，肩胯呈侧面；不能拿45°冒充 |
| 朝画面右90°全身 | 鼻尖朝右，独立生成；不能镜像另一张充数 |
| 背面180°全身 | 头部与身体一致朝后，体现后脑、衣背和鞋后侧 |
| 正面脸部特写 | 看清五官、发际线与肤色，不因放大换脸 |
| 上身服装细节 | 领口、口袋、扣子、面料与袖口对应同一套衣服 |
| 手部与袖口细节 | 手型与袖口一致，手指自然；短袖角色展示相应短袖或袖口可见部分 |

左右按**图像方向**描述，避免人体解剖左右与摄影方向混淆。正面原图可以作为来源引用并保留其原始SHA，不能谎称重新生成。其余角度分别绑定原生生成ID、保存节点与输出；可在一次请求内共享模型加载，但每个视图使用独立的描述、噪声、采样和保存节点。不对称细节不能靠镜像推断。

每个单图只呈现一个视图；总览图用于比对和选图，标签由后期排版加入。生成视频时选用所需单图，不能把带标签的九宫格直接送进画面生成。

## 身份与版本

每组绑定唯一人物ID、原始参考图SHA、外观设计版本和每个视图的生成请求、输出SHA。默认直接参考同一基准；难转向视图可以采用一张已经检查的邻近角度作为姿态参考，但必须同时记录该图与最终基准的来源，限制为这一跳，并回到基准图核对身份。不把上一张漂移侧面逐层传下去。

脸部或手部局部裁切只能帮助模型读取原参考，裁切位置需要记录；它不会凭空提供原图未记录的真实背面结构或高清皮肤细节。生成的未知部分属于造型候选，需要整组检查。

细节图以实际区域裁切作为单一图像参考，描述只要求该区域：脸部只说五官与头肩，服装只说对应领口/口袋/面料，手部只说手与可见袖口。不要同时把全身与头部裁切当作两个人物参考，也不要在特写需求里继续要求鞋、长裤和完整全身。本轮首版确实出现全身复制、脸部叠影；ROI单参照和区域提示修复后才继续审查。

当前成人与孩子基图是通用模型测试候选，不自动映射成小说苏墨或叶西决的正式设计；原小说角色的年龄依据、服装状态和角色ID仍需由正式角色卡绑定。

## 检查与返修

先检查视图齐全和原文件，再分别检查身份、年龄外观、体型、服装、朝向和手部。文件齐全不等于角度或身份通过。

单张角度错误仅重做该张；若基准形象本身需改，建立新版本并重检整组。背面出现正脸、90°仍为45°、左右靠镜像凑数、细节图与全身服装不符均不能按合格多视图放行。

旧视频批次保持暂停。此次候选与审查存放于 `data/image_model_trials/20261106_character_turnaround`，原11张模型测试图保留。
