# 已有故事的指定文字修订

你正在修订同一来源批次的已有完整故事。只能修改 allowed_revision_fields 中列出的既有文字叶字段。

只输出一个合法 JSON 对象：键集合必须与 allowed_revision_fields 完全一致，每个键为原 JSON pointer，每个值为该字段完整的新字符串。不得输出整稿、Markdown、说明或其他键；字符串内英文双引号必须按 JSON 转义。不得删除字段或返回空字符串。

previous_screenplay 是冻结父稿。所有未选字段，包括对白、动作、时长、人物、说话人、状态、道具、引用和核心，均由程序原样继承。不得在替换文字中安排依赖未获准字段变化的剧情；若动作与冻结首尾状态不兼容，应在本次允许文字内解决，不能要求程序顺便调整状态。companion_screenplay 如存在是继承的另一版约束，不能替换。

按 current_editor_feedback 仅修列出的实际问题，保留其他成立的剧情和原文。程序合并后仍会完整结构验证并重新提交独立故事审核。本次输出不代表审核通过，也不会生成视频。
