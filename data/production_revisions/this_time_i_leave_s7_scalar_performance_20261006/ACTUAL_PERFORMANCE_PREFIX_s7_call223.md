仅四镜已源核对，其余六镜、整片编译与联合复审未完成；这是工作进度，非最终制作交接。无媒体、无用户质量批准。

## SH01 / 完整表演 call208

编译计划时长：2.900000秒；不是实际媒体时长。

对白表演：本镜无对白。

**A0E0 / 1.4秒**：方澄站在自己浅木色工位前，灰蓝薄针织开衫垂落，白色圆领T恤领口微露。目光低垂落在桌面上，米灰色挎包已挂在椅背、电影票压在自己伸手就能够到的桌角，无视线巡看，双手自然垂于桌面边缘，身体保持安静站姿，不抬手、不取物。

源事件：方澄已站在工位前，挎包挂在椅背、电影票压在桌角，建立为自己留出时间的可见状态

**A1E0 / 1.5秒**：林屿坐在右侧工位，米驼色棉质衬衫袖口已挽至前臂，没抬头，右手贴着桌面轻推A4横版客户明细单，让它沿浅木色表面往两人之间的方向滑出约一掌距离，自己手收回原位。明细单仍停在林屿桌沿靠近方澄工位的那一侧，A4纵版结算单继续摊在他自己桌角，白色陶瓷咖啡杯放在近侧，签字笔仍搁在自己桌沿。

源事件：林屿没抬头，把A4横版客户明细单沿桌面滑向两人之间一侧，仍停在林屿桌面上

## SH02 / 完整表演 call212

编译计划时长：12.985714秒；不是实际媒体时长。

**林屿**：上月那张对账是你帮我熬到十一点重打的，今晚这份也对到一半了，你顺手帮我收了吧。

对白表演：林屿坐在方澄右侧工位，仍低着头朝自己桌面客户明细单，语气随口、不抬眼，嘴角微松，下唇先抿再松，像把一句已经默认会应的事平着说出来；眼区基本不动，视线压在纸面红笔批注上方，说到"重打的"轻顿一拍，"你顺手帮我收了吧"末尾气息略轻收，话尾不在等回应。

**A0E0 / 1.2秒**：方澄原本低垂的目光沿桌面平移，视线落在右侧林屿桌面客户明细单的红笔批注上，眼睛微收，眨眼一次，嘴唇合拢、不张嘴，呼吸浅而匀，脸上是听着的神色，没有要接话的动作。

源事件：方澄的目光移向林屿桌面客户明细单上的红笔批注

**A0E1 / 1.2秒**：方澄目光从红笔批注收回，再斜向自己桌角那张米白底深红字的院线电影票停住，眼里一闪轻而定的东西又沉下去，眉心微收不到蹙，唇线抿平，下颌轻压，没接话，也没把手伸向那张票。

源事件：方澄的目光从红笔批注移向自己桌角压着的电影票

## SH03 / 完整表演 call219

编译计划时长：5.300000秒；不是实际媒体时长。

**林屿**：对账，改明细，收尾。

对白表演：林屿随口列清单的低声：语气平直不加重，尾音稍顿成词点，三字节奏均匀带一点理所应当的笃定，不带请求意味；音量偏低，像在自己桌前念出三件待办，气息稳不叹气。

**A0E0 / 0.4秒**：林屿坐着将脸和上身微微转向左侧方澄工位方向，目光由原下垂顺势离开桌面前方。

源事件：林屿侧身将脸朝向方澄工位一侧

**A0E1 / 0.6秒**：林屿右手自方澄桌角一次轻轻捏起浅黄、浅粉、浅蓝三张叠在一起的便利贴。

源事件：林屿右手同步取起整叠三色便利贴

**A0E2 / 0.6秒**：林屿右手将三张便利贴整叠轻放在自己桌面上，浅黄在前左、浅粉居中、浅蓝在右并排摊开，纸张彼此贴近。

源事件：林屿右手将三色便利贴同步摊放在自己桌面同一支持面

**A0E3 / 0.2秒**：林屿右手指尖压住浅黄便利贴的右下边角不动，纸张保持摊平不被掀起。

源事件：林屿指尖压住浅黄便利贴边角，不移动纸张

**A1E0 / 0.5秒**：林屿右手松开便利贴边角，从自己桌沿自然拿起那支黑色签字笔握在右手掌中。

源事件：林屿从自己桌沿拿起黑色签字笔握在右手

**A1E1 / 0.7秒**：林屿右手反手将签字笔笔尖朝向方澄那一侧搁在自己桌沿停住，手指轻持笔身不松不推，安静等她来接。

源事件：林屿右手反握签字笔，笔尖朝向方澄一侧搁在桌沿停住等她接

## SH04 / 完整表演 call223

编译计划时长：3.300000秒；不是实际媒体时长。

对白表演：本镜无对白

**A0E0 / 0.5秒**：方澄目光落在林屿右手握着的黑色签字笔上，笔尖仍朝向自己这一侧，她没伸手，指尖微收了一下又松开。

**A0E1 / 0.6秒**：她的视线顺着那只握笔停住的手腕往上抬，慢慢对上了林屿的眼睛，下颌没有动。

源事件：方澄目光顺着那只握笔停住的手抬向林屿的眼睛

**A0E2 / 2.2秒**：她就这样看着他，嘴唇轻轻抿了一下又松开，呼吸比刚才浅一点，眼睛里那种被默认接活的压力慢慢被自己按下去。

源事件：方澄不伸手、不开口，眼睛保持对上林屿的目光，把拒绝前的犹豫留在眼神里
