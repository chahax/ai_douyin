# 当前能力

## 2026-10-02 当前创作主线（v22）

以完整剧本、导演安排、实际请求预览、逐段视频和人工审核为主线。阶段输入/结果、
字段投影、返修回放、停止控制、媒体来源链、成片交付及独立发布/运营回执已经接通。
真实视频内容仅由用户决定；系统技术成功统一进入 awaiting_human_review。仅完整成片
人工批准后可生成发布预览，再明确执行账号绑定浏览器发布；待核验保留提交锁。

创作质量机制已实现，真实金标、冻结留出和实测收益尚未被本轮开发回归证明。
当前实现与验证边界以 [创作平台实现](CREATIVE_WORKFLOW_IMPLEMENTATION.md) 为准；
下列旧视频自动生产停用说明针对已退出的历史节点，不等于当前明确执行候选生成被禁止。


| 模块 | 状态 | 说明 |
|---|---|---|
| 运营账号策略 | 可用 | 法律、小说领域策略可扩展 |
| 抖音真实账号绑定 | 可用 | 运营账号、浏览器环境、真实身份唯一绑定 |
| 登录健康检查 | 可用 | 页面身份核验，验证出现时要求人工处理 |
| 热门内容采集 | 可用但受平台验证影响 | 记录真实视频 ID、标题、作者、标签、时间和页面指标 |
| 标签族与时间趋势 | 可用 | 支持关键词、标签关系、流量快照和动量分析 |
| 内容分析与机会排行 | 可用 | 相关度、内容表现、时间、反馈和风险分项 |
| 账号维护 | 可用 | 相关内容调研、播放进度校验、自有作品与评论同步 |
| 选题和脚本审批 | 可用 | 继续保留，不再直接进入旧视频生成流程 |
| 自动视频生成 | 已停用 | 背景、人物驱动、图生视频、插帧和合成旧节点均已撤下，等待 V2 验收 |
| 自动生成并发布 | 已停用 | `video_pipeline=disabled_pending_redesign` |
| 人工发布已有 MP4 | 保留 | 必须核验绑定账号并由管理员明确执行 |
| 发布效果复盘 | 可用 | 同步作品指标和评论，回流下期选题 |

旧视频模块、脚本和样片仅为历史资产。代码存在不等于生产可用。
